# 0.4.4 新建方案模板

`synthetic.json`和`uh60-public.json`分别源自`examples/public-helicopter`的同名公开/合成模板。原几何、翼型和气动参数直接引用已有资产；仅新增版本化ID、来源说明和`trim.download_policy="none"`。旧文件保持原样。

新六分量方案不附加残余比例下载，机身和尾翼按原模型继续计算；机身下洗/下载仍有缺项。悬停预算继续使用原3%经验比例。页面和结果列出实际策略，比较两类功率时须保留这项方法差异。

此目录保留原方位参考和全部估计参数，未宣称改善物理精度。0.4.5的机尾零方位另建版本；旧包打开时不替换为新模板。
