# 整机悬停与前飞配平

同一版本2机型驱动主尾桨、机身与尾翼，在规定速度、高度和爬升率下联立求解六分量平衡。命令行与网页调用相同入口；姿态、操纵、功率、余量和失败原因随实际输入保存。

## 运行与设计比较

```powershell
.\.venv\Scripts\python.exe -m rotordesignlab run examples/trim/synthetic-case.json --out runs/trim-point
.\.venv\Scripts\python.exe -m rotordesignlab batch examples/trim/speed-sweep.json --out runs/trim-speed
.\.venv\Scripts\python.exe -m rotordesignlab batch examples/trim/mass-sweep.json --out runs/trim-mass
.\.venv\Scripts\python.exe -m rotordesignlab batch examples/trim/cg-sweep.json --out runs/trim-cg
```

网页选择“整机配平”。先选合成无人机或公开UH-60模板，再修改质量、速度、高度、爬升率和重心。专业设置提供径向/方位网格与扫描列表。点击提交才计算；结果页展示实际输入快照，修改表单尚未提交时仍保留上一次结果。

工况版本3：`model="helicopter"`、`analysis="trim"`。必填 `aircraft_json, speed_m_s, climb_m_s, altitude_m, requested_duration_s`；可选 `mass_kg,cg_x_m,radial_stations,azimuth_stations` 以及预算阶段的尺寸、转速和尾桨力臂变量。默认每桨80个径向站、整周36个方位站来自模板/工况。半径变化保持实际弦长、扭转和r/R站位，挥舞惯量、质量矩、铰偏置按输入保留；调整桨叶实体尺寸后应同时更新这些质量参数。

扫描版本1：`kind="helicopter_trim_sweep"`，`case_json`指定基准工况，`axes`含1–2个变量。第一轴按升序续接，第二轴每组独立初始化；失败点不更新初值。`continuation=false`可用于独立起算核查。每一点的`case.json`保存实际传入的18维`initial_state`（若使用续接），无需依赖前一点目录。

输出包括：

- `trim.csv`：T/Q/P、功率分解、姿态和操纵；`residuals.csv`：六分量归一化残差。
- `result.json`：求解/支持域/设计限制/验证依据四类状态、双向操纵和姿态余量、部件载荷及功率。
- `trim-diagnostics.json`：18维初值/终值、内部残差、迭代与限位信息；失败亦保存。
- `main-elements.csv`、`tail-elements.csv`：方位—径向局部速度、攻角、Mach、CL/CD与诱导速度。
- 扫描生成 `performance.csv`、功率/姿态与周期变距的PNG/SVG、Markdown报告。断线表示失败，红叉表示已收敛但超出给定限制。

导出目录或网页ZIP移到其他目录后，`run case.json`可复算单点，`batch batch.json`可复算整批。每次指定空输出目录；部分失败仍保留完整的逐点诊断。

## 方程与定义

机体系x前/y右/z下。旋翼局部z沿推力，x由`flight.x_reference_body`投影到桨盘，y=z×x。ψ从+x朝+y计，ψ点=旋向符号×Ω。操纵为总距、cosψ、sinψ三个系数；两项周期变距不是已经换算过的驾驶杆纵横位移。旋翼总距参考站按原几何文件定义。

叶素相对速度包含平移、旋转和一阶挥舞速度，攻角用四象限atan2计算。每方位对单桨积分，再整周平均乘桨叶数。稳态采用三状态Pitt–Peters及β0/βc/βs挥舞；每桨6个内部未知量，加主桨3操纵、尾桨总距和滚转/俯仰，共18个未知量。挥舞方程包含铰偏置、离心恢复、重力、弹簧和阻尼，固定模式直接指定预锥。

部件力与力矩统一变换到机体系、移到重心，加上姿态变换后的重力。功率为ΩQ，再计传动损失和附件。平飞约束机体系v=0；给定爬升率通过惯性系垂直速度闭合。纯垂直爬升时保留姿态变换产生的机体系侧向分量。定常直线飞行机体角速率为0。

同一机型中的`inflow_model`、`tip_loss`及旋翼顶层`precone_deg`供原孤立轴流/预算分析使用；`trim`采用本节三状态稳态入流，预锥/挥舞由`flight.flapping`定义，不叠加轴流环带模型或尖损失。这样保留两种分析用途各自的模型口径。

求解采用有界最小二乘，力除mg、力矩除mgR；六分量最大残差≤1e-4，内部各残差≤1e-6。最终重新检查全部气动数据域、正推力/轴功率、正贯流、峰值挥舞和主桨μ≤0.25。数值试探期间允许表端值延拓，最终解严格拒绝域外点。收敛点再检查操纵和动力限制，动力不足不伪装成求解不收敛。

机身输入α/β系数表、参考面积/长度/位置；尾翼输入弦线、法向、面积、安装角和极曲线。部件下洗系数与重心处残余下载系数均显式输入。其适用性依赖来源与工况，默认模板没有进行干扰参数标定。

## 验证依据与缺项

数值结果见[验收数据](../validation/trim/acceptance.json)、[工作记录](v030-work.md)。复算完整活动：`python -m tools.validate_trim --out <新的目录>`。单元测试验证载荷收支、功率、坐标、操纵限位、域外失败、搬移/断网复算和续接独立性。Streamlit交互检查为`python -m tests.check_trim_ui`。

UH-60主桨复用原`GHRotorData.mat`的CLR0BT/CDR0BT，按Julia列序变成攻角±32°、Mach 0–1二维表，CD加原程序的0.002。未用总距差或功率偏差拟合修正。原MAT还包含高攻角UT数据；它与BT表的分段衔接、原模型斜流攻角修正及回流载荷需要进一步互校，本版未将其自动接入整机示例。尾桨仍用注明来源的工程极曲线。

当前UH-60示例0–20m/s扫描通过，30/40m/s有主桨叶素越出BT表；合成模板40m/s越出其CSV表。μ≤0.25是上限条件，实际有效包线取数值收敛、局部气动域、挥舞和设计限制的交集。改变几何、质量或高度后需重新检查。

NASA TM-85890 [原报告](https://ntrs.nasa.gov/citations/19840015585)表4提供数学模型配平结果。`tm85890-table4.csv`来自PDF第21页/印刷第15页，已核对页面图像；比较文件为`tm85890-comparison.csv`。低速1/20/40kt点用于姿态差值比较，质量16400lb和重心FS360.4/WL247.2单独匹配。参考表未明确给出高度，本项目采用海平面ISA，使EAS与TAS数值一致，作为记录在案的环境假定。
