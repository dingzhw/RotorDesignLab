# 0.4.2 统一方案与详细设置工作记录

2026-11-15，从 c4c90a2 开始。用户已手动试用0.4.1，反馈基本满足要求。本轮将参数配置、方案保存重开与分析入口统一起来，沿用现有求解方程。

## 工作包一：字段与便携方案

- 建立统一中文字段字典，包括单位、正方向、参考点、模型用途及估算来源提示，覆盖机型版本2的全部可编辑字段。
- 方案包 `.rdl` 保存机型、几何、原翼型表和各分析工况。内部沿用JSON快照，用户通过网页操作，不编辑内部文件。
- 本地方案库位于 `private/designs`，不进入Git。保存采用原版本校验和原子替换；旧版本留在history，另一窗口修改同一方案时提示另存或重开。
- 校验复用原机型和旋翼输入检查，结构错误集中定位到中文字段。未知惯量允许缺省，开环分析时提示补齐。
- 验证包括两种完整机型及旧版孤立旋翼的数据往返、来源与原气动表保留、保存冲突、历史恢复、非法输入、惯量缺项，以及两机型搬移后悬停预算与原文件逐项复算。

## 工作包二：网页设置与入口统一

实施中。主入口按分析用途组织：孤立旋翼、整机悬停预算、整机配平、通用开环操稳。三片叶与原工程旋翼合为孤立旋翼，桨叶数和预设工况属于方案参数。原 Julia UH-60 80 kt 移到基准验证；它与通用Python整机模型具有不同方程和验证范围，保留复算入口。

详细设置与各任务共用同一当前方案。保存、重开、导入、导出、来源/未保存标识和实际运行快照一起检查；网页调整参数后与CLI同输入对照。Excel、CSV/TXT专用表导入按0.4.3继续；本轮几何和气动表可在网页中直接编辑。
