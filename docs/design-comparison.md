# 同一任务下的三方案比较（C1，0.4.6.dev11）

本包回答总体设计中的一个具体问题：**在相同飞行质量、飞行条件与功率维持时间下，调整主尾桨尺寸、转速或安装参数，会怎样改变功率需求、操纵余量及局部速度？** 本轮接通配置、求解、读图、保存和复算，沿用已经具备的稳态配平模型。

## 同事如何使用

1. 在“整机装配”准备基准机型，确认质量、旋翼、机身尾翼和动力来源。
2. 进入“全机配平”，选择“同任务三方案（功率与配平）”；填写共用速度、高度、环境和需维持时间。也可在“悬停求解”的预算任务中选择该入口，三方案改用六分量悬停配平。
3. 展开三个候选，填写名称、主桨半径与转速、尾桨半径与纵向力臂、重心X、半径变化规则和来源说明。候选默认是基准、主桨加大5%、主桨降速5%，均可修改。
4. 点击“运行分析”，查看三方案功率分项与四项操纵双向余量；失败候选保留原因，不绘成零功率。功率不足与求解失败分别显示。
5. 保存装配以保留修改过的候选设置；历史结果保留本次实际输入。可下载中文CSV、Markdown摘要与完整结果包，PNG/SVG图在结果包中。修改草稿后旧结果仍对应原输入。

当前比较是在同一基准装配上建立三个设计变体；独立装配库任意三选比较、任务包络比较和自动定尺寸尚未在C1接入。已有“预算—配平功率对照”回答的是同装配下两种模型的差异；原“三方案比较”仍保留预算变体及质量覆盖语义。

## 统一口径与实际输入

- 三方案共用飞行质量、水平速度、爬升率、高度、空气环境、维持时间、分析网格和六分量配平模型。候选禁止混入质量、高度等任务变化，避免把轻载或低高度误当作设计收益。
- 保持实际弦长：各r/R站位及扭转不变，实际弦长不变；半径增加时实度降低。保持实度：弦长随半径同比缩放，r/R与扭转不变。表内实度按实际桨根切除后的桨叶面积/名义桨盘面积定义。
- 总质量、桨叶质量矩、挥舞参数和机体惯量不自动缩放。因而尺寸变化是固定质量下的气动/稳态配平敏感性，不包含结构重量代价。已经启用A2显式质量分账的装配继续禁止未核对惯量的尺寸/重心覆盖，候选直接给出原限制。
- 页面重心X与尾桨力臂同时决定尾桨安装X，主桨及其他部件的绝对安装位置保持。CLI仅覆盖重心而未指定尾桨力臂时，尾桨绝对位置保持；结果保存实际位置和力臂。转速联动遵循原装配是否声明主尾桨速比。
- 共用B包功率账：主桨与尾桨气动轴功率、两路传动损失、附件功率；可用功率按实际高度与维持时间选连续/短时额定。下载所增功率已经包含在旋翼需求中，不重复加一项“下载功率”。
- 操纵余量是配平角到输入限位的差，分别给出主桨总距、cos/sin周期变距、尾桨总距到上/下限的距离。cos/sin相对实际安装基底和方位定义，不能无条件当成驾驶杆纵横方向。
- 每候选保存完整机型、几何/翼型、工况、输入哈希、计算诊断与来源。四项状态分开报告：求解、支持范围、设计限制、验证依据。R19开环用途限制保持，本包没有开启操稳方案排序。

## 三方案实算

复用B包的[冻结合成输入](../validation/power/inputs/synthetic/aircraft.json)，200 kg、海平面标准环境、15 m/s平飞、600 s、80径向叶素×36方位站。主桨基准半径1.1 m、1700 rpm，尾桨0.24 m、独立7500 rpm；连续动力45 kW，两路传动效率0.96/0.93，附件0.7 kW。机型、动力曲线与候选均为合成/工程估计，未用真实机型实测来证明本例精度。

|方案|主桨功率/kW|尾桨功率/kW|传动损失/kW|附件/kW|总需用/kW|连续余量/kW|主桨总距/°|主桨旋转桨尖Mach|
|---|---:|---:|---:|---:|---:|---:|---:|---:|
|基准|30.018|1.585|1.370|0.700|33.673|11.327|11.699|0.575|
|主桨半径+5%，保持弦长|28.730|1.484|1.309|0.700|32.223|12.777|9.945|0.604|
|主桨转速−5%|30.153|1.725|1.386|0.700|33.964|11.036|13.026|0.547|

本例增大半径使盘载由518.64降至470.31 N/m²，需用功率降低约4.31%，但旋转桨尖Mach提高；结构增重尚未计入。降速后总距增加，主桨扭矩和尾桨反扭矩需求增大，总功率增加约0.86%。这组差异给出需要继续检查的取舍，尤其小差值应结合翼型、损失和工程输入的不确定性判断，报告不自动判定最优方案。

三点都在当前稳态支持范围内且满足给定限制。另将共用连续动力曲线同比降低至海平面33.5 kW，三点仍收敛，但基准/降速方案功率超限，加大半径方案仍有余量，证明“收敛”与“满足设计限制”分开处理。

## 验证、复算与保留项

基线为`d6f2396` / `0.4.6.dev10`。没有修改旋翼、配平或动力学方程；新批量类型为`helicopter_design_comparison`，不替换旧批量类型。全库134项通过（212.193 s），包含旧工况、预算比较及模块/装配兼容。最后补充全失败、非有限输入、报告写入失败处理后，C1专项共6项通过（9.342 s）。

实际验证覆盖：固定任务防混用、基准候选与原单点逐值一致、弦长/实度规则、质量矩未自动改写、重心/力臂坐标关系、A2原保护、失败保留；三点功率收支与P=ΩQ、六分量归一化残差≤1e−4；搬移后关闭网络连接入口复算，三点summary与设计参数逐值相同。公开三点计算含绘图导出2.77 s，硬件与环境见验证JSON，此耗时不作为不同机器的性能保证。

自动网页检查覆盖前飞/悬停入口、编辑来源、方案包往返、历史重开、CLI复算、未提交输入隔离、失败后修正重跑；属于AppTest检查。本包未新增同事实测或新机器安装验收。既有人工实测记录保留。

本机记录在`runs/c1-comparison-20261118/`，含修改前哈希/备份及每次日志。首次网页命令缺少项目PYTHONPATH，设置当前进程路径后恢复；一项检查曾误把未修改控件的缺省值当成必须保存字段，改为实际编辑后验证包往返。另一个低功率探针错误地把所有高度连续额定设为33.5 kW，违反高空短时额定上限，被输入检查拒绝；修正为原曲线同比缩放后通过。原失败日志保留，未放宽物理或数值门槛。
