# 桨叶气动载荷与桨毂传力

2026-11-17，0.4.6-A1。独立传力核已实现；整机动力学接入及 R19 关闭尚未完成。网页继续使用原模型并显示交叉耦合限制。

## 受力对象与输入

`rotordesignlab/hub_loads.py` 对每个方位的一片刚性线桨叶列 Newton–Euler 平衡。轴系为右手系，z 沿推力正向；几何方位 ψ 从 x 向 y 增加，ψ̇=σΩ，σ=±1，Ω>0。挥舞 β 朝 +z 为正，其转轴为 −eψ，与旋向分别定义。

当前共同假设是定转速、无摆振、无弦向质量分布、无弹性自由度。几何、气动表和动力学的后续集成须使用同一实际基底。传力核接受完整的 β̇、β̈；调用者需要明确它们是完整时变运动，还是仅含周期运动的低频近似。

一片桨叶铰外长度为 ℓ，s 为距挥舞铰的距离，必须显式提供：

- m₀=∫dm，单片桨叶质量，kg；
- m₁=∫s dm，铰外质量一阶矩，kg·m；
- Iβ=∫s² dm，铰外质量二阶矩，kg·m²。

检查 m₁²≤m₀Iβ、Iβ≤ℓm₁、m₁≤ℓm₀。仅有 m₁ 和 Iβ 只能给出质量下界，不能唯一求出质量。本实现不会按这个下界自动填补机型质量。

## 运动学与传力方程

令铰偏置为 h，桨叶展向单位矢量 b=cosβ·er+sinβ·ez，挥舞法向 n=−sinβ·er+cosβ·ez。关于桨轴原点的位置为：

```text
x(s) = x₀ + s b,          x₀ = h er
v_rel(s) = σΩh eψ + s (σΩ cosβ eψ + β̇ n)
a_rel(s) = −Ω²h er
         + s [−Ω² cosβ er − 2σΩ sinβ β̇ eψ + β̈ n − β̇² b]
a(s) = a_h + α×x + ω×(ω×x) + 2ω×v_rel + a_rel
     = a₀ + s a₁
```

ω、α 是桨毂固定坐标系的机体角速度和惯性角加速度；a_h 是桨毂惯性平动加速度，均投影到当前旋翼基底。a_h 不等于机体系速度分量的直接时间导数，也没有预先扣掉重力。

输入的 F_a、M_a 是单片桨叶气动力及关于桨轴原点的气动力矩。输出为**桨叶作用在桨毂上的力和力矩**：

```text
F_h = F_a + m₀g − (m₀a₀ + m₁a₁)
M_h = M_a + (m₀x₀+m₁b)×g
    − [m₀ x₀×a₀ + m₁(x₀×a₁+b×a₀) + Iβ b×a₁]
```

弹簧、阻尼已通过桨叶运动和平衡进入这一传力关系，不能在 M_h 上再次叠加。关于铰点的力矩是 M_h−x₀×F_h。它在自由轴 −eψ 上的投影满足：

```text
(M_h−x₀×F_h)·(−eψ) = K(β−β_pre)+Cβ̇
```

此式成立的条件是 β̈ 满足相同受力下的挥舞方程。自由铰时右端为零；有偏置时，关于桨轴原点仍有 x₀×F_h。固定桨叶的约束弯矩通常不为零。

共同挥舞惯性广义力为 n·(m₁a₀+Iβa₁)。`SteadyRotor.evaluate` 已改为调用这个表达式，允许显式传入桨毂加速度和角加速度。现有整机调用仍传零，因此此次替换保持原求解语义。

## 质量矩阵及整机接入门槛

传力核返回每片桨叶对 [a_h, α] 的 6×6 惯性系数。令 c=∫x dm，J=∫[(x·x)I−xxᵀ]dm，S(c)v=c×v，则：

```text
K_blade = [ m₀ I   −S(c) ]
          [ S(c)     J   ]
Δ[F_h, M_h] = −K_blade Δ[a_h, α]
```

矩阵对称，含平动和转动耦合。其按实际安装基底变换、移到同一参考点后，才可与机身方程组装。独立质量点积分与变换后的矩阵已作检查。

现有 `mass_properties` 是整机给定质量与惯量。将上述 F_h/M_h 原样塞进当前整机方程，会重复计入桨叶重力、平动质量和一部分惯量。后续接入必须选定并记录一种一致的分账方式：提供非旋转机体质量、质心和惯量，或从已明确参考桨叶姿态的整机质量性质中扣除旋转桨叶，再组装完整系统。扣除后还要检查物理可行性。输入质心的变化也需要计入。

此外，现有 β₀/βc/βs 是代数未知量。若其随状态变化，完整 β̇、β̈ 还含慢变幅值导数；仅给机体方程加一个经验陀螺项不能闭合这些量。A2 将明确保留的低频阶次，并处理由共同挥舞方程和机体方程产生的隐式加速度；A3 才进行整机导数与响应验收。

## 已完成检查与 OH-6A 诊断

解析平衡采用 F_scale=m₀Ω²(h+ℓ)、M_scale=F_scale(h+ℓ)，归一化门槛 1e−6；近零解析量绝对门槛 1e−8 N 或 N·m。独立空间位置五点差分及质量点积分检查正反角速度、双旋向、桨毂加速度和角加速度；自由铰、偏置、弹簧/阻尼及固定边界均通过。惯性矩阵检查用 1e−10 SI 绝对误差，坐标变换和移轴检查用 1e−12。

复用专家 OH-6A 包，在悬停和 20.58 m/s（原包标称40 kt）先按现有模型配平。随后只对主旋翼做角速率扰动，分别冻结入流和求准定常入流；桨毂惯性加速度和角加速度按诊断协议给零。全部输出为机体系分量，力矩参考点为桨轴原点，单位 N·m/(rad/s)。下表采用 m₀=1.5m₁²/Iβ=14.286678 kg 的**质量敏感性假设**，不是 OH-6A 实测桨叶质量。

|速度|入流处理|气动 ∂My/∂p|传力 ∂My/∂p|气动 ∂Mx/∂q|传力 ∂Mx/∂q|
|---|---|---:|---:|---:|---:|
|悬停|冻结|14486.38|226.69|−14487.18|−227.49|
|悬停|准定常|14441.80|182.00|−14442.35|−182.54|

12组“速度×入流处理×质量假设”的全部18项角速率载荷导数均检查步长减半，最大相对变化约0.1211%，低于2%门槛；近零导数分母使用1e−4 N/(rad/s)或N·m/(rad/s)绝对尺度。完整结果见 `validation/hub-loads/`。

这一结果支持“叶素气动力矩直接进入机体方程是主要异常来源”的诊断，并显示了惯性传力修正的量级。**它还不是整机 M_p/L′_q**：尚未闭合主尾桨质量与加速度，也没有完成 CR-3144 的杆系、带撇导数和完整有符号表格对照。原 R19 限制保持。

质量从下界9.524452 kg变到两倍下界19.048904 kg时，悬停准定常 ∂My_h/∂p 从200.92变为163.09；前飞从128.65变为90.82。质量归属虽不是原异常的大项，也足以影响修正后的残量，必须补齐。
