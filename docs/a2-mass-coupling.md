## 模型及质量归属

旧文件没有`dynamics`时仍调用`legacy_aero_v1`：原15状态、原总质量/惯量、原准定常挥舞和气动力矩路径。历史模板及包不改写。新模型`harmonic_hub_v1`由用户显式选择，并要求声明：给定总质量、重心和惯量包含主尾桨全部桨叶及旋转桨毂；惯量对应逐安装位指定的参考锥度/cos/sin挥舞幅值，经方位平均。

每副旋翼必须提供单片质量m₀、铰外一阶矩m₁和二阶矩Iβ，以及旋转桨毂的质量、局部重心、惯量与来源。模块已有字段直接投影至机型，不在装配另填一套。m₁²/Iβ只作质量下界检查，不作为缺失质量的自动估计。当前线桨叶质量全部位于铰外；实际根部质量若在铰内，须另计入合适部件，不能直接混用整个实物桨叶质量。

以给定参考重心为固定机体点O，空间质量矩阵为：

```text
K(m,c,Jcg) = [ mI      −mS(c)          ]
            [ mS(c)    Jcg−mS(c)S(c)  ]
Kcore = Ktotal(reference) − Σ Kblades(reference) − Σ Khub
```

c为部件重心相对于O的位置，S(c)v=c×v。局部桨毂运动映射为`T=[[Bᵀ,−BᵀS(r)],[0,Bᵀ]]`，惯量用`TᵀKT`变换。扣除后检查机体质量为正、重心惯量正定及主惯量三角关系。桨毂须轴上重心、轴对称张量，其自旋角动量`Jzz σΩ`参与陀螺力矩。偏心或非轴对称桨毂当前拒绝。

u/v/w表示固定参考点O的机体系速度，瞬时全系统重心可随挥舞变化；不把它重新解释为随桨叶移动的质心速度。全机重力不再重复加入右端，机体、主尾桨桨叶和桨毂各计一次。

## 挥舞与机体共同方程

将挥舞幅值视为随状态变化的代数量，却只保留每转周期运动，会漏掉慢变幅值的动量反作用。本包对每副铰接旋翼保留三个一阶谐波幅值及其三个变化率：

```text
β = H(ψ)b,  H=[1,cosψ,sinψ], ψ̇=σΩ
β̇ = H ḃ + Ḣ b
β̈ = H b̈ + 2Ḣ ḃ + Ḧ b
q̈ = [aO, αbody, b̈main, b̈tail]  （固定桨叶省略对应b̈）
M(q) q̈ = Qexternal(q,q̇,inflow,controls) − Qbias(q,q̇)
```

单铰接主桨＋固定尾桨为21状态，双铰接为27状态；全固定桨叶为15状态。气动力使用同一叶素核和完整β̇，挥舞及传力使用同一β̈。按虚功与Galerkin投影组装机体—挥舞交叉项，检查质量矩阵正定后联立求解。`v̇=aO−ω×v`，桨毂加速度为`aO+α×r+ω×(ω×r)`。弹簧/阻尼只进入共同挥舞方程，不向传递力矩重复叠加。自由铰约束按保留谐波投影成立，高阶剩余项仍由旋翼诊断显示。

E是真实联立方程在配平点的加速度系数，含非对角项；F=EA、G=EB。姿态及幅值运动学行使用单位系数，入流行使用原Mpp/Ω。配平、差分和时程共用载荷及质量实现。模型仍是方位平均刚性一阶谐波，不包含逐桨叶通过载荷、摆振、弹性及高阶谐波；附加高频模态未经独立验证，公开评价频段仍限低频。
