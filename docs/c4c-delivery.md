# C4-C：五入口方案操作与离线交付

版本0.4.6.dev18，基线b99b965，2026-11-19。工程问题是让同事用一致的操作管理旋翼和整机方案，从装配进入性能计算、保存结果并在另一目录复算。数值核、旧文件格式和模型用途限制保持。

## 操作和参数

五入口均采用“新建、打开、保存、更多”。孤立旋翼管理旋翼方案；整机装配、悬停求解、全机配平和开环评估使用同一个整机方案身份，各分析工况分别保存。分析页面只读装配快照，修改安装、质量、动力仍回到整机装配。

- 替换未保存草稿时提供取消、保存后继续、放弃修改并继续；取消保留原草稿和结果。复制另建编号；恢复历史先进入草稿，保存后才写回库。
- 整机增加可恢复删除，使用与保存相同的锁和版本哈希检查。回收区恢复另建副本；并发修改不会被静默删除。
- 装配直接接收孤立旋翼导出的方案文件，只取旋翼本体及气动资产。安装位置、方向、传动和整机工况独立；模块库变化不改已有快照。
- 尾桨独立给定转速时显示转速，联动时只显示主尾桨速比；点击应用后修改有效装配。质量—高度扫描和速度扫描分别由点列给定扫描量，返回单点保留原值。
- 来源资料仍随输入保存，安装备注放入可选折叠区。结果统一提供“下载结果与可搬移复算包”，方案文件与结果ZIP用途分别说明。

旧格式整机方案原样打开和保存，转换为模块化装配仍需显式操作。旧孤立算例及下降失败记录继续保留；没有因界面调整升级入流、挥舞或动力学模型。R19开环交叉耦合问题仍开放，只允许故障诊断，不恢复稳定性评价或方案排序。
