# 工程环境、单位与实时预览

0.4.5新增内容与“详细设置”共用当前方案；保存、重开及导出的方案包会保存本次环境模式与数值。

## 环境与动力

新建统一机型默认“高度与ISA温差联动”。这里的高度按0–11000 m的ISA气压高度解释：高度先确定标准压力，相对ISA温差改变实际温度，再由同一个温度计算密度、声速与动力黏度。温差15°C就是15 K。海平面零温差约为15°C、1.225 kg/m³、340.294 m/s；高温降低密度、提高声速并提高动力黏度。

基准常数沿用原悬停预算实现，零温差时保持旧数值。密度采用理想气体关系，黏度采用Sutherland关系；基本依据见[NASA大气状态说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/earth-atmosphere-equation-metric/)与[NASA黏度说明](https://www.grc.nasa.gov/www/BGH/viscosity.html)。这是干空气工程模型，没有增加湿度或实测天气模型。

“自定义完整环境”同时填写密度、声速、动力黏度。三项分别进入动压、Mach及Re计算；提供的气动表仍决定有效数据范围。网页会回显本次实际空气参数；切换环境模式属于物理工况编辑，不像运动速度视角那样自动保持同一状态。

旧孤立旋翼方案继续使用原密度及原声速/黏度缺省，重开后显示为自定义环境。旧整机工况未填环境时仍使用原标准大气。维护人员可使用可选`environment`对象：`mode=isa`配`isa_temperature_offset_k`，或`mode=custom`配`density_kg_m3/speed_of_sound_m_s/dynamic_viscosity_pa_s`。孤立旋翼禁止同时填写此对象和旧式顶层空气参数，避免两个输入来源冲突。批量密度扫描采用自定义环境；ISA模式按其高度和温差计算密度。

连续功率、短时功率、附件耗功和旋翼轴功率限值在页面使用kW，文件和求解器继续使用W；保存、重开和CSV复算不需要用户换算。可用动力功率仍只由输入的高度曲线决定。现有模板没有温度降额曲线，ISA温差不会自动修改发动机或电机的可用功率。

## 草稿预览与结果

- 侧视/俯视使用实际桨毂位置、半径、安装基底、尾翼气动中心和重心，虚线是位置连接。它是安装示意，不是外形CAD。
- 桨叶页实时显示弦长与原表扭转。计算仍按总距参考站扣除扭转参考值；图示不会改动原表。
- 翼型页显示所选展向站和Re层的Mach曲线。高攻角独立分支分开画，不跨缺口补线；同时显示原始域与来源。数据未补齐时保留表格，提示预览缺项。
- 常用结果表使用中文工程名和kW，提供中文CSV下载。原SI字段仍在复算文件中；四项结果状态分别解释求解、范围、设计限制和验证依据，完整原始诊断保留在下一级专业区。

检查记录见[0.4.5工作记录](v045-work.md)。实际环境输入、坐标核对和保存复算属于软件与数值验收；原旋翼气动偏差和低频操稳适用范围保持。
