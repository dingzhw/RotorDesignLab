# 孤立旋翼：总距、三方向来流与气动力

进入“孤立旋翼”，直接填写**本次总距 θ₀**、**本次旋翼转速**，再填来流。总距定义在机型指定的参考站，例如 r/R=0.75，几何扭转相对此站归零。固定总距正算给出拉力和功率；指定拉力反求会求出总距或转速，并在结果中显示实际计算值。

## 来流怎么填

新建方案默认填**飞行器运动速度**：水平前向、水平右向、上升为正，单位m/s，相对静止空气。前向沿机头在地平面的投影；默认机体水平，“姿态与速度参考系”可另填滚转、俯仰。

“速度输入视角”也可切换为**空气相对旋翼轮毂**的机体系分量：X向前、Y向右、Z向下。切换会转换数值、保留同一物理速度；下方实时列出实际XYZ和所选旋翼推进比。旧方案仍默认原来的XYZ视角，不改变保存值。两种输入均不含旋翼自身诱导速度。

下表为水平姿态时的空气来流值；非水平姿态由程序变换，不直接照抄符号。

|常规向上主旋翼的工况|X / (m/s)|Y / (m/s)|Z / (m/s)|
|---|---:|---:|---:|
|无风悬停|0|0|0|
|无风前飞20 m/s|−20|0|0|
|空气向机体右侧流动5 m/s|0|5|0|
|无风上升3 m/s|0|0|3|
|组合来流示例|−15|−4|3|

盘面内来流通常称为桨盘内来流；“切向速度”是相对某个桨叶径向位置、方位角的局部分量。程序先把机体系向量转换到旋翼坐标系，再逐方位角分解出切向和法向速度，叠加旋转速度、诱导速度及挥舞速度。尾桨按自己的安装轴自动变换，不把机体Z方向直接当作尾桨轴向。

“周期变距、挥舞与计算网格”内可给cos/sin周期变距：`θ(ψ)=θ₀+θcos cosψ+θsin sinψ`，另计几何扭转与桨距—挥舞耦合。ψ从旋翼+x朝+y增加，+z为正推力轴，+y=+z×+x。方位参考由机型给定；旧版无方位参考时，依次选机体X/Y/Z中不与推力轴接近平行的方向，投影到桨盘，输出实际坐标变换矩阵。

桨叶运动可选固定桨叶或机型挥舞参数。固定模式采用旋翼一级预锥角；机型模式使用`flight.flapping`的预锥、惯量、铰偏置、弹簧与阻尼，并求解锥度及一阶挥舞。默认周期变距为0，固定桨叶。

使用机型挥舞参数时，桨叶重力方向随输入姿态转换；旧工况未填姿态时继续取机体水平。这里没有轮毂角速度输入。输出表仍只列气动力，完整运动状态请使用整机分析。

## 结果是什么

- 拉力为沿正推力轴的整转平均气动力；轴扭矩Q和轴功率P按驱动旋翼的正功率定义，`P=ΩQ`。
- 表格列出机体系Fx/Fy/Fz，以及关于轮毂和重心的气动力矩。力矩按右手定则，移轴使用 `(轮毂位置−重心位置)×力`。这里是气动载荷，不包含整机重力或整机配平。
- 新增方位角—半径攻角图和单片桨叶轴向气动力密度图，并保留整转平均径向载荷。图表坐标采用中文和常用专有符号。
- 下载包含实际工况、机型、几何、翼型、方案包、载荷CSV、PNG/SVG及摘要；保存方案会保留本次总距、转速、来流和模型选项。

## 模型选择与适用范围

“三方向来流”复用整机现有方位角叶素及稳态Pitt–Peters三状态入流/一阶挥舞方程。三状态入流描述平均、cos和sin入流分量，模型路线可查[NASA入流模型综述](https://ntrs.nasa.gov/citations/19900051466)。本入口尚无独立前飞旋翼试验精度验收，结果保留模型估算状态。

首期支持正推力、正轴功率、悬停和正贯流，盘面内推进比μ≤0.25，同时要求当地攻角、Mach和Re落在所给翼型表支持范围内。无Mach维度的极曲线当地叶素合速度限制为250 m/s。下降/反向贯流、涡环态、自转、非定常失速、展向气动力、尾流旋转和旋翼间干扰尚未接入。输入三个速度分量并不消除这些物理范围限制。

“轴流性能”保留原均匀/环带入流与Prandtl选项，用于既有XV-15、C–T等对照。两种模型不做隐式切换；0.4.2旧方案重开时保留轴流选项，新方案默认三方向模型。三方向模型不采用环带/Prandtl修正。

## 验证与复算

0.4.5-A的运动视角使用`flow_body = −R_body_to_heading.T @ [前向,右向,−上升]`，其中水平航向参考系的第三轴向下。运动视角和XYZ视角共用一次标准化入口；导出工况保存实际`flow_body_m_s`及姿态，方案包另存输入视角。维护人员也可直接给`motion_m_s`（水平前/右/上）与`attitude_deg`（滚转/俯仰）；两个速度字段须二选一。批量变量`motion_forward/right/climb_m_s`与旧`flow_x/y/z_m_s`分别保持自己的参考系，不在同一扫描混用。正反转换、双旋向、主尾桨、非水平重力方向及导出复算见[本轮记录](v045-work.md)。

`tests/check_spatial_benchmarks.py`生成[数值检查记录](../validation/isolated-3d/checks.json)。合成算例同时给[-15,−4,3] m/s，120×48到240×96的T变化0.000722%，Q/P变化0.000374%。坐标旋转、旋向、主尾桨安装方向、力矩移轴、叶素积分和正反求一致性均有测试。

C–T 1250 rpm、8°、0.5°预锥的CT为0.00641699，相对原试验0.0046仍高39.50%。相对旧均匀入流结果的T差0.003126%、Q/P差0.000833%，来自Pitt–Peters采用名义桨盘面积、旧轴流动量方程采用预锥投影面积；零预锥下T相对差为4.24×10⁻¹¹。原径向模型29.09%的试验偏差及其解释继续保留。这些记录用于说明模型差别，没有拟合新修正系数。
