# v0.3.0 工作记录与验收

起点：v0.2.0 / 362f99d，开发分支 codex/rotordesignlab。本轮授权实现方位角叶素、周期变距、挥舞，再接悬停/正爬升/无侧滑直线前飞六分量配平。现有未跟踪论文保留。

## 工作包

- [x] A：方位角叶素与周期变距；四象限运动学、旋向、载荷/功率和悬停极限检查。
- [ ] B：三谐波挥舞平衡与三状态Pitt–Peters稳态；独立公式、网格、公开悬停对照。
- [ ] C：版本2机型扩展与部件载荷，六分量配平；缺项聚合、限制与失败诊断。
- [ ] D：模板、续接扫描/界面/导出，公开UH-60模型互校和范围记录。

每包检查后提交、同步并核对服务器SHA。旧旋翼/预算入口保持复算。六分量归一化残差≤1e-4，旋翼内部残差单列；网格末两级总量目标≤0.2%。前飞主桨μ≤0.25，同时受局部翼型和挥舞范围约束。闭环、下降涡环、自转与动态稳定性不在本版本。

## 坐标与模型约定

旋翼局部z沿正推力，局部x由机型给出的方位参考向量投影到桨盘，y=z×x，构成右手系。ψ从+x向+y计，旋向s规定ψ点=sΩ。总距/周期变距和挥舞系数均按[常值,cosψ,sinψ]排列；不把它们直接命名为驾驶杆纵横向量。机体系仍为x前/y右/z下，所有部件统一移算至重心。

叶素相对空气速度包含平移、转动和挥舞速度；攻角使用atan2并包络到[-180,180]。每个方位积分单桨，然后整周平均乘桨叶数。回流区要求相应四象限翼型输入；最终状态禁止表端外推。现阶段忽略展向气动力、弹性扭转、旋流和尖涡细节。

来源：原J-GenHel公开方程/坐标约定作为互校；[NASA TM-84281](https://ntrs.nasa.gov/citations/19830001781)附录C提供刚性桨/挥舞/整机模型背景；[NASA动态入流综述](https://ntrs.nasa.gov/citations/19880007248)与原Julia入流矩阵用于符号、稳态极限核对。公式口径和本项目简化逐项记录，不声称完整复刻原报告模型。
