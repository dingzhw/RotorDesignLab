# 独立旋翼网页工作区

0.4.6.dev4建立M2；0.4.6.dev5接通M3装配，2026-11-18。

双击“启动旋翼设计台.cmd”，在左侧选择“孤立旋翼”。此页只需要一个旋翼，不要求飞机重量、重心、惯量、动力、安装位置或另一副旋翼。主旋翼与尾桨在独立分析时都是同一种旋翼模块；安装角色在M3装配时绑定。

## 第一次计算

1. 初始载入合成三桨叶模块。需要公开模型时，在“模块库”选择UH-60公开基准旋翼并新建。合成模板属于工程估计，公开模板缺失的质量资料仍留空。
2. 在“本次旋翼工况”直接填写**总距、转速和三方向速度**。选择运动速度视角时，程序将它取负转换为空气相对桨毂速度，并回显实际参与求解的三分量。
3. 在“空气环境”选择高度/ISA温差联动，或者填写密度、声速和动力黏度。这是本工况唯一环境入口。
4. 默认使用模块的挥舞特性。需要对照时，可选固定桨叶；轴流性能法仅支持固定桨叶、纯轴向来流、零周期变距。三方向法采用方位角叶素和Pitt–Peters三状态入流，不会自动切换模型。
5. 点击“运行旋翼计算”，查看拉力、扭矩、轴功率、局部六分量气动载荷、径向载荷和方位图。修改参数后，上次结果保留并明确标为旧结果；只有重新运行才生成对应新输入的结果。

坐标为局部右手系：z沿正推力轴，x为零方位，y由右手系确定。+1旋向从+x转向+y，从正z端看向桨毂为逆时针。这里没有机头或机尾；安装到飞机后才建立机体系映射。当前支持正贯流：运动z≥0，空气相对速度z≤0；盘面内分量可正可负，仍受推进比、翼型数据域等模型检查限制。

“周期变距、试验姿态与计算网格”提供周期变距、局部重力和离散参数。水平向上旋翼的重力为[0,0,−9.80665] m/s²；竖直试验台按实际姿态投影，例如[0,−9.80665,0]。零重力仅用于数值对照。

## 编辑旋翼本体

“旋翼详细设置”分为几何与旋向、桨叶质量矩、桨毂质量属性、挥舞特性、操纵与载荷限制、几何与翼型数据表。字段提供中文名称、单位和问号提示。

- 单片桨叶质量、一阶质量矩、挥舞惯量分别填写。质量矩按挥舞铰外距离积分，不由质量猜测。未知量关闭“填写”复选框，保持缺项。
- 桨毂质量、局部重心和重心惯量单独保存。目前稳态挥舞使用桨叶一阶/二阶质量矩；桨毂质量与单片质量不会自动累加到整机，也未接入A2惯性耦合。
- 预锥保留旧文件的两种模型语义：“挥舞特性”中的预锥供“采用模块挥舞特性”使用；“固定对照预锥”供固定桨叶对照使用。切换处理方式时页面回显固定对照的实际值。
- 几何表和单张极曲线可直接编辑，或下载CSV后用Excel修改再导入；TXT支持逗号或制表符分隔。下载表列名须保留，中文含义和单位见页面表头与提示。
- 展向/Re/Mach气动表可以逐站、逐Re层编辑CL/CD和高攻角分支；当前主数据层支持CSV下载和导入，导入保持攻角及Mach网格。新增多维气动数据网格仍通过已有数据准备工具完成，本包不增加气动数据生成能力。

## 保存、重开与历史

“保存旋翼算例”保存模块、全部气动表、本次工况和扫描定义到`private/rotor-modules/`。同名条目以短编号区分；“另存为新旋翼算例”创建新编号。保存时检查另一窗口是否已经修改同一条目，有冲突则保留当前草稿并提示另存或重开。

每次覆盖保存前保留历史版本；可以恢复历史到草稿，再保存生成新版本。“移入回收区”保留可恢复文件和当前草稿，“恢复副本”生成新编号，不覆盖现有模块。替换未保存草稿需要勾选页面内的替换选项。导入失败保留原草稿。

下载提供两种用途明确的文件：

- **旋翼模块（.rdlr）**：旋翼本体和气动表，供后续整机装配。纯模块重新导入时使用模块限位中值作为总距/转速试验初值、零来流和水平旋翼重力，计算前需核对。
- **旋翼算例（.rdlc）**：模块及本次工况、扫描设置、提取来源，可重开继续编辑。内部结构由程序管理，同事无需编辑JSON。

从旧`.rdl`整机包提取时，源包只读；选择一副旋翼生成独立草稿。包内有匹配的最后一次孤立工况时，可以按原安装基底转换来流和重力；没有时明确载入参考工况。原包SHA-256、原安装基底和位置保留在迁移记录中，不参与新模块的重心移轴。语义有歧义或包含未支持覆盖项的旧工况明确拒绝转换。

## 反求、扫描与复算

“指定拉力反求”可选择反求总距或转速，边界采用模块限位。另一个操纵量保持给定值。不可达时保留失败诊断。

“批量性能扫描”支持1至2个变量：总距、转速、高度、局部空气速度x/y/z。一次最多100点；高度扫描要求ISA联动。每点使用相同单点入口，分别保存结果与输入。失败点在性能曲线上留空，表格保留原因。改变工况不自动改变几何、质量矩或挥舞参数。

“下载结果与可搬移复算包”包含实际模块、工况、结果、表格及已有PNG/SVG图。解压到新目录可用原CLI复算：

```powershell
python -m rotordesignlab run case.json --out replay
# 扫描包使用：
python -m rotordesignlab batch batch.json --out replay
```

模块与整机草稿分开保存，切换左侧入口不会串用输入或结果。进入“整机装配”，可将已保存模块加载到主旋翼或尾桨安装位，设置位置、方向和传动，保存固定快照。模块库更新不自动更换已有装配；从装配进入孤立旋翼编辑副本后，仍需显式换入。“悬停求解”分别提供功率预算和六分量悬停配平，工况和结果各自保存。操作见[整机装配说明](assembly-workspace.md)。开环R19诊断限制保持。
