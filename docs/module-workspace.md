# 独立旋翼网页工作区

0.4.6.dev17更新C4-B坐标与有效参数，2026-11-18。

双击“启动旋翼设计台.cmd”，在左侧选择“孤立旋翼”。此页只需要一个旋翼，不要求飞机重量、重心、惯量、动力、安装位置或另一副旋翼。主旋翼与尾桨在独立分析时都是同一种旋翼模块；安装角色在M3装配时绑定。

## 第一次计算

1. 初始载入合成三桨叶模块。需要公开模型时，点击“新建”，选择UH-60公开基准旋翼。合成模板属于工程估计，公开模板缺失的质量资料仍留空。
2. 先在“旋翼设置”编辑本体，再填写三方向速度和空气环境，选择求解任务；正算给定总距和转速，反求只给目标拉力和另一个已知量。新方案运动速度采用固定参考系前/右/下，程序按试验姿态转换成桨盘来流并回显。旧方案保留原局部向量，详见[C4-B说明](c4b-engineering-inputs.md)。
3. 在“空气环境”选择高度/ISA温差联动，或者填写密度、声速和动力黏度。这是本工况唯一环境入口。
4. 在旋翼设置选择铰接挥舞或刚性桨叶，只有实际生效的预锥入口；轴流性能法仅支持固定桨叶、纯轴向来流、零周期变距。三方向法采用方位角叶素和Pitt–Peters三状态入流，不会自动切换模型。
5. 点击“运行旋翼计算”，查看拉力、扭矩、轴功率、局部六分量气动载荷、径向载荷和方位图。修改参数后，上次结果保留并明确标为旧结果；只有重新运行才生成对应新输入的结果。

坐标为局部右手系：z沿正推力轴，x为零方位，y由右手系确定。+1旋向从+x转向+y，从正z端看向桨毂为逆时针。这里没有机头或机尾；安装到飞机后才建立机体系映射。当前支持正贯流：运动z≥0，空气相对速度z≤0；盘面内分量可正可负，仍受推进比、翼型数据域等模型检查限制。

“周期变距”提供θc/θs；“试验姿态与坐标示意”提供试验姿态及重力加速度g。固定模式隐藏重力。网格在“求解器参数设置”；轴流方法隐藏不使用的方位离散数。

## 编辑旋翼本体

“旋翼设置→详细设置”分为总体参数、桨叶质量矩、桨毂质量属性、挥舞特性、操纵与载荷限制、桨叶几何形状、翼型气动数据。字段提供中文名称、单位和问号提示。

- 单片桨叶质量、一阶质量矩、挥舞惯量分别填写。质量矩按挥舞铰外距离积分，不由质量猜测。未知量关闭“填写”复选框，保持缺项。
- 桨毂质量、局部重心和重心惯量单独保存。目前稳态挥舞使用桨叶一阶/二阶质量矩；桨毂质量与单片质量不会自动累加到整机，在装配选择A2模型后按显式分账参与惯性耦合。
- 预锥界面只显示当前有效值，保留旧文件的两种模型语义：“挥舞特性”中的预锥供“采用模块挥舞特性”使用；“固定对照预锥”供固定桨叶对照使用。切换处理方式时页面回显固定对照的实际值。
- 几何表和单张极曲线可直接编辑，或下载CSV后用Excel修改再导入；TXT支持逗号或制表符分隔。下载表列名须保留，中文含义和单位见页面表头与提示。
- 展向/Re/Mach气动表可以逐站、逐Re层编辑CL/CD和高攻角分支；当前主数据层支持CSV下载和导入，导入保持攻角及Mach网格。新增多维气动数据网格仍通过已有数据准备工具完成，本包不增加气动数据生成能力。

## 保存、重开与历史

“保存”将旋翼本体、气动表、工况和扫描设置写入本机方案库。打开时选择本机方案或文件；同名条目以短编号区分。“更多→复制方案”创建新编号，保留原方案。保存保留历史版本，并检查另一窗口是否修改了同一方案。

替换未保存草稿时提供“保存后继续、放弃修改并继续、取消”。失败导入保留草稿。历史版本与回收区在有记录时显示，恢复不会删除历史。

“更多→导出方案文件”输出一个`.rdlc`文件，可在孤立旋翼重开，也可直接载入整机装配。装配只提取旋翼本体，保留自己的工况。仍能读取已有`.rdlr`模块文件；旧整机提取工具继续供历史复算使用，不再作为普通页面入口。

来源自动继承，修改值标记为用户修改待核；备注可选。新建普通方案的轴功率和扭矩上限默认未启用，可在限制组填写；打开或复制旧方案保留其限制。未填写的限制显示为未评估，不代表无限动力。

## 反求、扫描与复算

“指定拉力反求”可选择反求总距或转速，边界采用模块限位。另一个操纵量保持给定值。不可达时保留失败诊断。

“批量性能扫描”支持1至2个变量：总距、转速、高度、局部空气速度x/y/z。一次最多100点；高度扫描要求ISA联动。每点使用相同单点入口，分别保存结果与输入。失败点在性能曲线上留空，表格保留原因。改变工况不自动改变几何、质量矩或挥舞参数。

“下载结果与可搬移复算包”包含实际模块、工况、结果、表格及已有PNG/SVG图。解压到新目录可用原CLI复算：

```powershell
python -m rotordesignlab run case.json --out replay
# 扫描包使用：
python -m rotordesignlab batch batch.json --out replay
```

模块与整机草稿分开保存，切换左侧入口不会串用输入或结果。进入“整机装配”，可将已保存模块加载到主旋翼或尾桨安装位，设置位置、方向和传动，保存固定快照。模块库更新不自动更换已有装配；从装配进入孤立旋翼编辑副本后，仍需显式换入。“悬停求解”分别提供功率预算和六分量悬停配平，工况和结果各自保存。操作见[整机装配说明](assembly-workspace.md)。开环R19诊断限制保持。
