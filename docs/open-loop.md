# 通用低频开环分析

本开发版接通统一机型的配平、A/B、特征根、参与状态、四操纵频响和阶跃时程。它采用六自由度刚体、主尾桨各三状态动态入流、准定常锥度/一阶挥舞，共15个状态。当前交付版本为 `0.4.0.dev1`；完整动态挥舞、桨叶惯性/桨毂加速度耦合和操稳物理精度验收仍待完成。

```powershell
python -m rotordesignlab run examples/open-loop/synthetic-linearize.json --out runs/my-linearization
python -m rotordesignlab run examples/open-loop/uh60-response.json --out runs/my-response
python -m streamlit run app.py
```

网页选择“通用开环操稳”，从合成无人机或公开UH-60部件模板开始。填写速度、质量、重心，提交后运行。下载ZIP含完整机型、翼型、几何、实际工况、CSV矩阵与曲线、PNG/SVG和Markdown摘要。将导出目录搬移后，用其中case.json可复算。惯量由机型给定，改变质量不会自动缩放惯量；这种独立修改须符合所比较方案的物理配置。

## 状态与操纵

状态顺序：`u,v,w,p,q,r,phi,theta,psi, main_lambda0,main_lambdac,main_lambdas, tail_lambda0,tail_lambdac,tail_lambdas`。机体系前/右/下，速度m/s、角速率rad/s、姿态rad、入流无量纲。位置不进入状态；航向为运动学中性模态。主尾桨转速固定，环境固定于配平高度。

操纵为 `main_collective,main_cos,main_sin,tail_collective`，矩阵B单位按rad，输入阶跃幅值`amplitude_deg`按度。cos/sin由机型桨盘方位参考定义，旋向在机型内；两项不直接等同于原UH-60纵/横杆英寸量。UI和报告保留原始操纵定义及双向余量。

配平与时程调用同一套部件载荷；各桨毂、叶素、机身和尾翼的局部速度包含`ωbody×r`。准定常挥舞平衡含恒定机体角速率的科氏及向心项。每次RHS用固定配平初值解挥舞代数方程，无历史缓存影响差分；叶素瞬态包含一阶随方位挥舞速度，暂不含挥舞系数的时间导数。

动态PP使用原GenHel压力矩归一化，状态顺序重排为`[λ0,λc,λs]`，表观质量为`diag(128/(75π),16/(45π),16/(45π))`。冻结来流方向时与原Julia矩阵独立互校；当前采用固定桨轴下旋转后的算子，未加尾迹曲率及变化风轴的输运修正。此说明限定了动态互校范围。

体轴平动为`m(vdot+ω×v)=F`，转动为`Iωdot+ω×Iω=M`；力F含重力。导出E/F/G满足`E δxdot=F δx+G δu`，其中E含机体质量/惯量和两桨PP表观质量除转速。A=E⁻¹F、B=E⁻¹G。未实现的桨叶惯性反作用、旋翼自转角动量和桨毂加速度耦合在本版没有对应隐式项，不以单位质量阵假装完成全阶耦合。

## 数值与适用范围

先要求配平和旋翼内部稳态通过；再以中心差分计算A/B并将步长减半，逐列检查主要导数变化≤2%。主要导数定义和缩放阈值随`linearization.json`导出，近零项另记录绝对变化。未通过时保留矩阵并返回失败。翼型、Re、Mach、部件表域、μ≤0.25、操纵和姿态限制持续检查。

频响范围限于0.01到`min(3,0.1Ωmain)` rad/s；默认0.1起。CSV相位在±180°内，图上展开相位。特征根表保留全部15根，标记是否在低频范围；快速入流根用于检查数值刚性，完整高频物理验证未完成。阻尼、周期、e折衰减/发散时间和左右特征向量参与因子均导出，不自动判飞行品质等级。

非线性时程采用固定步RK4，线性常值阶跃采用矩阵指数精确推进。合成小旋翼具有快入流模态，建议时间步0.001s；公开UH-60模板建议0.01s，程序同时检查相对于最快局部模态的步长。积分越界保存最后有效部分，不将部分时程标成完整成功。功率/扭矩可行性字段针对配平基点，暂未验收瞬态动力系统与功率约束。

响应误差逐状态按原SI单位导出；综合范数用明确保存的状态尺度无量纲化。若存在不稳定根，频响表示线性传递函数的代数结果，实际自由响应仍会增长。

原v0.3模板及Julia 80kt基准不变。新增公开模板见`examples/public-helicopter`：主桨原BT/UT全攻角数据、尾桨旧Re表、原机身/尾翼系数；混合了显式工程假设。尾翼±90°外采用可见的反向流对称估计，尾桨在40/50m/s仍可能Re越界。详见[本轮工作记录](v040-work.md)。

## 验证来源与待补数据

- 数学检查：解析刚体质量/惯量关系、叶素局部角速率、Julia冻结来流PP算子、配平代入动态方程、矩阵质量关系、差分/扰动/时间步检查、目录搬移和Python断网复算。
- 公开互校：[NASA TM-85890](https://ntrs.nasa.gov/citations/19840015585) 表5/6/8的Xu、Zw、Mq另列固定入流和消去稳态入流两种口径。参考启用PBA和主动平尾，并用1ft/s、5deg/s有限扰动；当前为原始桨距操纵、冻结总距参考平尾、局部导数。保留这些差异，不用控制口径不同的杆量导数判断产品精度。
- 待补：真实尾桨完整气动数据和结构约束、主尾桨/垂尾干扰、PBA与平尾控制配置、旋翼转动惯量/桨叶动态及耦合、独立飞行动态试验。C–T问题仍需非局部尾迹/尖涡及真实Re气动数据，不能从总距差拟合通用修正。

验收结果由`tools.validate_open_loop`和`tools.compare_public_derivatives`生成，公开摘要保存在`validation/open-loop`。完整v0.4发布继续以既定里程碑要求为准。
