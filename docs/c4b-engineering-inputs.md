# C4-B：试验坐标与有效参数

版本0.4.6.dev17，基线3550fd5。范围为独立旋翼输入、保存与显示；气动、入流和挥舞方程保持原实现。继续服务总体与初步设计，不增加独立旋翼瞬态任务。

## 同事如何使用

1. 在旋翼设置选择“铰接挥舞”或“刚性桨叶”。预锥只填写一处：刚性模式是给定几何角，铰接模式是弹簧零力矩参考角。受载锥度β₀在结果中显示。
2. 刚性模式不要求挥舞惯量、刚度、阻尼或重力；如需准备装配，勾选“编辑装配用质量资料”。切换运动方式保留已录入资料。
3. 新方案默认水平向上试验台，桨盘X向后、Y向右、Z沿正推力轴向上。可输入相对空气的“向前、向右、向下”运动速度，也可输入桨盘XYZ来流。标准姿态下运动(10,3,2)对应来流(10,−3,2) m/s。向下运动对应下降侧输入，仍会被现有模型拒绝。
4. 需要倾斜或竖直试验台时，在“试验姿态与坐标示意”填写姿态并应用。此动作保持桨盘来流数值、改变其在固定参考系中的方向，并重新投影重力。仅切换速度显示方式不改变物理工况。
5. 铰接模式在姿态表单填写重力加速度g，默认9.80665 m/s²。零重力只用于数值对照。坐标矩阵和箭头来自同一转换实现。
6. 新方案使用三方向方位角模型，包括零速和轴向工况。入流说明为“Pitt–Peters三状态入流的稳态解”；动态状态仍在整机时程中推进。方法对照放在专业区，显式选择轴流时才显示环带/均匀入流、Prandtl选项；不会随速度静默换核。

固定参考系B为前右下，旋翼局部系R为X零方位/Y右手系/Z推力轴。列向量矩阵为

`R = Rz(偏航) Ry(俯仰) Rx(滚转) diag(−1,1,−1)`。

姿态角按右手正向，单位度；这是试验台相对固定参考系的姿态，不是随来流方向变化的风轴。转换为`V_air,R = −Rᵀ V_motion,B`、`g_R = Rᵀ [0,0,g]`。力和力矩仍输出在原桨毂局部系，不在显示端翻转相位。旋向、零方位及周期系数的计算定义保持原有实现。

## 旧方案与文件

没有姿态记录的旧方案继续显示桨盘来流；铰接方案的原重力向量在高级区保留。不凭局部向量猜测机头方向。明确应用新姿态才创建姿态资料，页面同时说明该动作对重力的影响。

旧固定对照继续使用`rotor.precone_deg`，旧模块模式继续使用`flapping.precone_deg`；界面只编辑实际生效的一处。选择新的运动方式是显式修改，不改写历史文件。自由铰K=0时参考预锥不会产生弹簧恢复力矩。

带姿态的旋翼方案采用workspace清单版本2，新增独立版本的`trial`资料，局部工况及模块格式不变。读取兼容版本1/2，无姿态方案仍按版本1保存。新文件需用dev17及之后版本打开；CLI继续使用原schema 4局部工况。装配只取旋翼本体，不继承试验姿态。姿态与局部重力不一致时明确拒绝保存/读取。
