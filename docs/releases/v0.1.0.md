# RotorDesignLab v0.1.0

首个可复算的本机分析版本：UH-60 80 kt 基准与通用轴向旋翼分析。

## 功能

- Julia UH-60：配平、固定方位与方位平均全阶线化、短时非线性开环响应。
- Python 单旋翼：固定桨叶的正推力悬停和正轴向来流，输出拉力、扭矩、功率及径向载荷。
- 中文 Streamlit 界面、统一 JSON/CSV、命令行复算、失败诊断和下载。
- 保留 J-GenHel 来源、作者 Umberto Saetti、MIT 许可及论文引用。
