# RotorDesignLab v0.2.0 · 整机悬停功率与方案比较

给定单主旋翼＋尾桨方案，现在可计算无地效悬停的主尾桨总距、载荷、轴功率及连续/短时动力余量，并扫描质量、高度、旋翼尺寸/转速和尾桨力臂。

- 机型版本2和整机工况版本3；继续读取旧机型、旧工况。
- 重量/下载与偏航反扭矩闭合；分列主桨、尾桨、传动损失、附件耗功，保留侧力和未闭合力矩。
- 合成无人机与公开UH-60参数模板；来源、估计极曲线、动力假设明示。
- Streamlit“整机悬停预算”入口，三类设计图、具名方案比较；CSV、PNG/SVG、Markdown、输入快照和ZIP下载。
- 不改动Julia基准；v0.1.0标签保持可复算。当前开发/发布内容位于codex/rotordesignlab。

## 验收

26项Python回归、新旧界面AppTest、目录搬移及禁止Python网络连接的复算通过。两模板120/240/480叶素末两级关键总量最大变化0.000220%，预算归一化残差远低于1e-4。

Ryzen 9 5900X / Windows 11 / Python 3.14.3，每桨240叶素：进程内单点约0.05–0.06秒，100点扫描含导出绘图36.60秒。100点中61收敛、39未闭合；收敛点中27超给定限制，诊断均保留。

三方案总需用功率为41.891 / 39.344 / 41.391 kW；完整参数与分项见 [预算说明](../hover-budget.md) 及 `validation/hover-budget`。

C–T独立标量求解的T/Q与产品相对差约1e-12，原始气动节点重建差为0；同总距试验拉力仍高估29.09%，径向MAPE26.04%。既有Hover_BENCHMARK中13份公开输入/归档结果哈希复核一致，未重跑历史DUST。

## 范围与后续

本版本交付功率与载荷预算，闭合Fz/Mz；整机六分量配平与开环操稳分别在v0.3/v0.4实现。整机结果标记为模型估算。UH-60预算模板使用工程极曲线和示例可用功率，不能等同于Julia原模型或实际T700动力裕度。

Re多切片、log(Re)插值与数据域检查已有实施约定，当前未新增Re求解能力；C–T物理偏差仍待有来源数据与尾迹/有限展长模型排查，不用总距修正拟合。详见 [C–T记录](../caradonna-tung-validation.md) 和 [后续路线](../roadmap.md)。
