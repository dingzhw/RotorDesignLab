# C2工程输入：几何、扫描与中文表格

本包版本为`0.4.6.dev12`，面向总体与初步设计中的快速改参和方案比较。新建演示机型名称统一为 **千机-200轻型无人直升机**，A2模板带“质量分账，试验性”后缀。更名不改变参数数值或来源性质：现有参数仍含工程估计，历史方案和验证记录原样保留。

## 从几何到计算

进入“孤立旋翼 → 旋翼设置 → 详细设置 → 桨叶几何形状”，展开“生成直线变弦与线性扭转桨叶”。输入有效桨根半径比、有效桨根/桨尖弦长、根部/桨尖扭转、几何站数和来源说明，查看预览后点击“应用生成几何”。

有效桨根是气动几何的内侧起点，必须位于总距参考站以内。生成的是根梢间线性弦长和线性扭转；几何站数与求解叶素数分开。局部桨距仍为“总距＋当地扭转−总距参考站扭转”，正扭转增加桨距。生成操作不改半径、桨叶质量矩、桨毂、挥舞属性或整机参数；需要结构重量重估时另行修改并注明来源。

应用后可以直接计算、保存旋翼方案或导出方案文件，再在整机装配中加载。原曲线不是线性分布时，生成会替换其几何分布；预览期间原表保持。已有非线性几何可继续使用表格编辑，不强制转换。旧版整机旋翼编辑器也提供同一生成与导入入口；现代装配仍从独立旋翼模块加载。

## 扫描如何填写

- 孤立旋翼“批量性能扫描”新增“步长”方式；原“起点、终点、点数”及导入的不等间隔点列继续使用。
- 悬停质量—高度、尺寸—转速、尾桨尺寸—力臂，以及配平速度/质量/重心扫描，均可选择“数值点列”或“起点/终点/步长”。旧点列是缺省，只有主动选择步长后才生成新点列。兼容孤立旋翼入口的扫描也使用同一方法。
- 终点是包含边界，不额外添加偏离步长的点。例如0到1、步长0.3，实际点是0、0.3、0.6、0.9；0到0.3、步长0.1则包含0.3。下降点列使用负步长。页面回显实际点列和总工况数。
- 求解器仍接收原版本的显式点列。独立旋翼最多100工况；整机扫描保持原1000点、最多12条分组曲线限制。配平按原有升序续接规则执行，保存每点实际工况。
- 步长为零、方向相反、非有限值或点数超限时提示错误并阻止启动，保留原扫描及上次结果。旋翼算例重开保存的是实际点列，旧不等间隔点列不会自动均匀化。

## 中文表格往返

用“下载……中文CSV”取得模板，Excel可直接打开。支持UTF-8（带BOM）和GB18030编码、逗号分隔CSV或制表符TXT。几何/普通极曲线同时接受中文列名和原英文列名，来源说明可随表保存。原生XLSX本包未接入，无需安装新依赖。

|表格|可修改内容|应用前检查|
|---|---|---|
|桨叶几何|半径比、实际弦长m、几何扭转°、来源|站位递增、末站1、正弦长、总距参考站位于有效桨叶内|
|普通翼型极曲线|攻角°、CL、CD、来源|有限数值、攻角递增、CD非负|
|Re/Mach翼型当前数据层|当前展向站/Re层/CL或CD的系数值、来源|攻角及Mach网格保持；其他层和独立高攻角分支不变|
|同任务三方案参数|方案名称、主尾桨尺寸/转速/力臂、重心X、几何规则、来源|三行且名称唯一、列名明确、数值有限、规则与来源有效|

表格先显示导入预览，点击应用才修改草稿。无效字段给出行号和中文名称；不自动排序数据、不填零补缺。模型适用范围与机型限位仍在相应输入/求解阶段检查。三方案表只包含设计变量，共用任务条件仍由上方填写。方案来源、实际几何和展开的点列随原有方案/结果格式保存，普通用户无需编辑JSON。

下载示例：[桨叶几何](../validation/c2-inputs/桨叶几何示例.csv)、[翼型极曲线](../validation/c2-inputs/翼型极曲线示例.csv)、[三方案参数](../validation/c2-inputs/三方案参数示例.csv)。几何示例是线性生成的演示分布，未替换原默认非线性几何；极曲线为已有工程估计数据。
