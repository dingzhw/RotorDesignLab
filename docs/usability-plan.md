# 面向设计所同事的易用性迭代

2026-11-15；起点711d669（0.4.0.dev1），沿用codex/rotordesignlab。本阶段冻结计算方法，重点让同事可以独立建方案、计算和理解结果。版本号表示软件迭代，已有模型适用范围和验证结论随结果保留。

## 第一轮：0.4.1——中文显示与日常启动

开发检查期间使用0.4.1.dev1。

- 图表坐标、标题、图例改为中文；保留CT、CQ、r/R、u/v/w、p/q/r、cos/sin及标准单位。统一中文字体，SVG内嵌字形，保证转发后仍能显示。
- 增加根目录双击启动入口，自动启动本地服务、等待就绪、打开浏览器。提供中文服务控制窗口；重复点击复用本项目服务，端口占用时选空闲端口，退出时只停止自己启动的进程。
- 环境首次准备与每天使用分开。当前同事仍需一份已准备Python依赖的本地目录；缺少环境给中文提示和日志位置。安装包与离线分发在第三轮形成。
- 验收：全部产品绘图路径生成中文图；代表PNG实际查看、SVG字形检查；启动、端口冲突、重复启动、关闭、带空格/中文路径、缺环境提示检查；数值输入与结果字段保持兼容。

## 第二轮：0.4.2——统一机型与旋翼详细设置

先完成字段字典，再实现表单；不把JSON键名直接搬到页面。一个方案贯通孤立旋翼、悬停预算、配平和开环。工作包顺序如下：

1. 字段字典：中文名、符号、单位、物理含义、方向/参考点、可用范围、默认值来源、影响的分析任务。坐标/旋向提供示意说明。缺失量显示“待补充”，不使用0代替未知。
2. 方案管理：从公开机型或合成模板新建、另存方案、重命名；切换分析任务不丢参数。未保存修改可辨识；恢复默认前提示将改变的内容。
3. 页面“详细设置”分组：基本信息、质量/重心/惯量、主旋翼、尾桨、机身、平尾/垂尾、传动与动力、操纵限位、分析网格。常用项先显示；专业项折叠并有说明。三分量向量、惯量、功率随高度曲线、桨叶几何均用有单位的表格编辑。
4. 页面输入在计算前统一检查；错误定位至分组和字段。结果显示“本次使用的方案与工况”，未提交修改不混入旧结果。JSON留作内部快照和旧工况兼容格式，普通流程不要求编辑或填写JSON路径。

验收：两模板都能仅靠网页修改质量、重心、主尾桨几何/转速、尾翼和动力限制；保存、重开、计算、导出再导入一致；同一输入与旧CLI数值一致。按分析任务集中提示缺项，特别区分预算、配平、操稳的要求。

## 第三轮：0.4.3——工程表格导入与新人交付

- 提供Excel工作簿模板：说明、方案信息、质量惯量、主尾桨安装/操纵、桨叶几何、机身/尾翼、动力曲线和参数来源。字段有中文名、单位、示例和数据验证。导入先预览，再检查，用户确认应用到当前方案。
- 专用表支持Excel、UTF-8 CSV和制表符TXT：几何为半径比/弦长/扭转；翼型采用长表（翼型或展向站、Re、Ma、攻角、CL、CD），避免让用户手填多层JSON。缺Re/Ma维度有明确含义；保留原高攻角分段边界，不把源表静默拼成另一种插值模型。
- 列名/单位映射、Excel行号/CSV行号错误提示，重复节点、空值、排序、表域、百分数及长度单位检查；导入不得执行宏或公式。显示来源及估算标记。
- 形成已准备依赖的现代Windows离线分发流程、版本页、可复制诊断信息、中文快速入门和三个工作流：孤立旋翼、整机预算/配平、开环分析。默认仍采用本机网页；只有实际部署或交互需求证明有必要，才更换桌面框架。

验收：一位未参与开发的同事，按说明完成双击启动→选模板→改参数→运行→读图→导出，全程无需终端或JSON编辑器。检查Excel/CSV/TXT往返一致、非法表格可修复重试、目录搬移和断网运行。远期Win7/Python3.8另行适配，当前不混入该分发包。
