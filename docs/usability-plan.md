# 面向设计所同事的易用性迭代

历史起点为2026-11-15的711d669（0.4.0.dev1），沿用codex/rotordesignlab。以下前三轮记录已经推进的易用性工作；2026-11-16评审复核后的未来安排以[开发路线](roadmap.md)为准。界面改进和物理模型改动分包验证，已有数值及精度记录保持其原范围。

## 第一轮：0.4.1——中文显示与日常启动

开发检查期间使用0.4.1.dev1。

- 图表坐标、标题、图例改为中文；保留CT、CQ、r/R、u/v/w、p/q/r、cos/sin及标准单位。统一中文字体，SVG内嵌字形，保证转发后仍能显示。
- 增加根目录双击启动入口，自动启动本地服务、等待就绪、打开浏览器。提供中文服务控制窗口；重复点击复用本项目服务，端口占用时选空闲端口，退出时只停止自己启动的进程。
- 环境首次准备与每天使用分开。当前同事仍需一份已准备Python依赖的本地目录；缺少环境给中文提示和日志位置。原定的完整离线分发尚未交付，现排入0.4.6。
- 验收：全部产品绘图路径生成中文图；代表PNG实际查看、SVG字形检查；启动、端口冲突、重复启动、关闭、带空格/中文路径、缺环境提示检查；数值输入与结果字段保持兼容。

## 第二轮：0.4.2——统一机型与旋翼详细设置

先完成字段字典，再实现表单；不把JSON键名直接搬到页面。一个方案贯通孤立旋翼、悬停预算、配平和开环。工作包顺序如下：

1. 字段字典：中文名、符号、单位、物理含义、方向/参考点、可用范围、默认值来源、影响的分析任务。坐标/旋向提供示意说明。缺失量显示“待补充”，不使用0代替未知。
2. 方案管理：从公开机型或合成模板新建、另存方案、重命名；切换分析任务不丢参数。未保存修改可辨识；恢复默认前提示将改变的内容。
3. 页面“详细设置”分组：基本信息、质量/重心/惯量、主旋翼、尾桨、机身、平尾/垂尾、传动与动力、操纵限位、分析网格。常用项先显示；专业项折叠并有说明。三分量向量、惯量、功率随高度曲线、桨叶几何均用有单位的表格编辑。
4. 页面输入在计算前统一检查；错误定位至分组和字段。结果显示“本次使用的方案与工况”，未提交修改不混入旧结果。JSON留作内部快照和旧工况兼容格式，普通流程不要求编辑或填写JSON路径。

验收：两模板都能仅靠网页修改质量、重心、主尾桨几何/转速、尾翼和动力限制；保存、重开、计算、导出再导入一致；同一输入与旧CLI数值一致。按分析任务集中提示缺项，特别区分预算、配平、操稳的要求。

## 第三轮：0.4.3——先修正日常操作与三方向来流

用户试用后调整优先级：总距与转速直接显示在孤立旋翼计算页，详细设置放到常用工况之后；多数参数提供悬浮提示；统一使用桨叶、桨尖。复用方位角叶素与三状态入流，接入机体系三方向来流、周期变距、固定或机型挥舞参数、六分量气动力及总距/转速反求。旧方案保留原轴流算法。验证与范围见[v043工作记录](v043-work.md)。
