# 整机装配与分析工作区

M3，0.4.6.dev5，2026-11-18。

使用顺序为：**孤立旋翼配置/计算 → 保存旋翼算例 → 整机装配加载模块 → 保存整机 → 悬停、配平或开环诊断 → 查看历史和导出复算**。首次使用可直接从合成直升机或公开UH-60部件模板开始。

## 装配一架直升机

在左侧进入“整机装配”。当前支持一副主旋翼加一副尾桨，共用轴功率接口。

1. 在“方案管理”选择完整直升机模板，点击“从模板新建”。新模板自动建立模块快照和两个安装实例。旧整机包仍能按原格式读取；需要改成模块化管理时，点击“将当前方案另存为模块化装配草稿”，再保存。原包不改写。
2. 用“选择安装位与角色”选择主旋翼或尾桨。打开“加载或替换旋翼模块”，选择已保存的旋翼算例，或上传模块包/算例包，再点击装入。相同模块可以装在两个安装位，位置和方向彼此独立。
3. 在“安装位置、方向、操纵与传动”填写桨毂位置、参考转速、配平总距初值和传动效率，点击“应用位置与传动设置”。安装角另有“应用安装角”按钮，未应用的表单值不进入求解。
4. 在整机详细设置中填写总质量、重心、惯量、机身、尾翼、动力曲线、下载假设及限制。这里不再维护另一套桨叶或挥舞参数；需要修改旋翼本体时，将安装快照的副本载入孤立旋翼工作区编辑、保存，再回到装配页显式换入。
5. 点击“检查整机装配”。基本结构和快照通过后，还分别检查预算、配平和开环诊断所需输入。缺项、越界或数据域问题按实际分析继续检查。

模块载入只取旋翼本体，不沿用该孤立算例的总距、转速、来流、空气环境或试验台姿态。安装位原有的参考转速、初值、位置和方向保持；如果不满足新模块限制，页面提示修正。

## 坐标、操纵和传动

机体系为X向前、Y向右、Z向下；桨毂位置、整机重心和机体气动部件共用原点。模块的局部z沿正推力轴，局部x为零方位。安装基底将局部力转换到机体系，随后按桨毂到整机重心的力臂移轴，统一使用现有载荷实现。

新主桨模板的零方位按机尾投影定义，尾桨模板按机头投影定义。旧方案保留原向量；安装角界面回显实际方向，查看不改变旧数据。改变零方位会改变周期变距分量的物理方向，需要重新核对操纵。

旋向属于模块，在安装页只读。方位角ψ从局部+x朝+y几何增大，桨叶实际经过方位的时间次序由旋向决定。当前操纵直接定义为桨叶变距角：`θ=θ₀+θc cosψ+θs sinψ`。主桨提供总距和两个周期分量，尾桨提供总距；尚未引入连杆传动或飞控指令到桨距的映射。

主桨使用给定参考转速。尾桨可独立给定，或采用“尾桨转速=主桨转速×速比”。速比模式会贯通单点和主桨转速扫描；与速比不一致的尾桨转速覆盖会明确拒绝。界面回显实际转速，装配快照和生成的机型均保存该关系。当前每副旋翼的轴功率分别除以其传动效率，再加附件耗功；不另加隐含的重复传动损失。

## 三类整机分析

分析页只读取当前装配，常用工况独立保存；需要修改设计参数时回到装配页。未保存的装配草稿也可计算，结果仍绑定实际提交的快照。

- **悬停求解**分为“功率与载荷预算”和“六分量悬停配平”。预算闭合垂向和反扭矩收支，显示剩余侧力；六分量配平使用与前飞相同的整机方程，将水平速度和爬升率固定为零。二者的高度、环境、网格和结果分别保存。
- **全机配平**给定速度、爬升率和环境，求姿态与操纵。保留现有速度、质量和重心比较。扫描是以装配快照为基准的显式工况/设计覆盖，实际输入保存在各计算点中，不回写模块库或基准装配。
- **开环评估**保留现有低频诊断能力及R19门槛。已知铰接旋翼交叉耦合问题未关闭时，需明确勾选“仅作故障诊断”，结果继续显示具体限制。

旋翼模块质量字段已归到本体，但A2尚未接通质量分账和隐式加速度。整机仍按旧模型的总质量/重心惯量计算，不自动把模块质量再加一次；桨毂质量缺项也不会填零冒充已知。

## 快照、历史和复算

装配包仍使用`.rdl`，内部方案格式升级为2，内含装配版本1、各安装实例的完整模块快照及来源；求解用机型格式仍为版本2。打开旧格式1包不会自动转换。新装配包校验模块内容哈希，并检查生成的旋翼参数/气动表与快照一致。模块库更新不会改变已有装配，只有明确换入才创建新的草稿状态。

装配编辑后，上次结果保留并标记为旧结果。每次网页整机计算另存一个不可覆盖的本地结果包到`private/assembly-results/`；各分析页的“本任务历史结果”可读取旧结果，跨网页会话仍可查看，不覆盖当前装配或工况。读取历史时注意其机型名称、日期和实际输入。

结果下载包含原有机型、工况、CSV/图表、`.rdl`方案包，并增加`assembly.json`和中文装配摘要CSV。`assembly.json`记录运行基准装配，扫描/设计覆盖后的最终值以各点`aircraft.json`和`case.json`为准。搬移目录后仍可复算：

```powershell
python -m rotordesignlab run case.json --out replay
# 批量结果包：
python -m rotordesignlab batch batch.json --out replay
```
