# 无人直升机总体设计分析路线

阶段目标：给定一份方案，快速计算孤立旋翼性能、整机需用功率与配平、动力和操纵裕度、开环动态特性，并比较设计参数变化。

已发布v0.1.0基准、v0.2.0悬停预算与v0.3.0定常整机配平。当前为v0.4开发版，先接通通用低频开环分析。Python为产品主线，Julia UH-60作为数值基准；保留旧工况复算。试验精度与数值收敛分别记录。

## 已完成：v0.3.0 配平

已形成方位角叶素、周期变距、锥度/一阶挥舞、三状态稳态入流、机身/平尾/垂尾共用载荷入口，闭合定常六分量。悬停、稳定正爬升、无侧滑直线前飞（μ≤0.25且不超局部翼型域），支持速度/质量/重心续接扫描、网页和导出复算。

数值检查含六分量≤1e-4、内部稳态≤1e-6、零速连续性、网格、操纵与动力限制。UH-60当前公开/工程混合模板通过0–20m/s扫描；30m/s主桨BT表越界。NASA TM-85890低速姿态比较最大俯仰/滚转差0.580°/0.569°，带配置差异保留。详见[配平记录](trim.md)和[工作包清单](v030-work.md)。

## v0.4.0 开环操稳

同一机型与动力学方程产生 A/B、特征根、参与状态、频响和小扰动响应，显式处理质量矩阵。导数步长减半变化目标≤2%，时步减半响应变化≤1%。输出双向操纵余量及性能—配平—操稳联合比较，不自动判飞行品质等级。

已接入低频15状态模型：6自由度刚体、两桨动态PP入流、准定常一阶挥舞；同一载荷函数驱动配平与时程。公开部件模板补齐机身、尾翼、尾桨挥舞/δ3及气动数据，原v0.3模板继续保留。网页和命令行共用linearize/response入口，输出矩阵、曲线与快照。

正式v0.4仍需：动态挥舞及惯性耦合、公开动态试验或充分匹配的独立模型验证、统一性能—配平—操稳方案比较验收。尾桨高/低Re数据、遮挡与结构约束、平尾/PBA配置也需补齐；本次开发版不提前标记这些项完成。[本轮记录](v040-work.md) · [开环说明](open-loop.md)。

## 验证与效率

保留 XV-15、C–T、UH-60。软件回归、数学模型互校、试验对照分别归档。末两级网格总量变化≤0.2%；固定总距拉力、同拉力功率和径向载荷误差目标分别≤10%，按独立基准判定，未达标保留模型估算状态。原有 C–T 固定总距拉力偏高约29.09%，继续排查但不阻止整机接口开发。

测量本机硬件和网格：预算单点目标≤2秒，后续配平≤30秒、100点扫描≤10分钟。暂缓前飞以外复杂构型、涡环态、自转、闭环与 Win7 分支。复用既有 Hover_BENCHMARK，不重复历史高成本计算。公开仓库只保存公开/合成输入与可公开成果。
