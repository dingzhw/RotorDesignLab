# 无人直升机总体设计分析路线

2026-11-16 评审复核修订；基线 `0.4.3.dev1 / 4ab78dd`，分支 `codex/rotordesignlab`。

目标：给定一份无人直升机方案，快速计算孤立旋翼性能、整机功率与配平、动力和操纵裕度、开环动态特性，并比较设计参数变化。近期先完善给定方案分析，之后接入需求驱动定尺寸。名称保持 RotorDesignLab｜旋翼设计台。

本文件是后续执行路线的唯一入口；[评审整改跟踪表与复核回复](reviews/RotorDesignLab-v0.4.3-评审意见回复书.md)记录 R01–R18 的处理和关闭状态，[AGENTS](../AGENTS.md)规定日常开发约定。原易用性计划保留历史，未来节点以本页为准。

历史验证：环带模型 XV-15 同拉力功率平均低估约 5.44%；C–T 同总距拉力高估约 29.09%，均匀入流约 39.50%。旧 Re 表替换后约 28.87%，未解决主要偏差。UH-60 姿态和部分导数属配置有差异的数学模型互校。各套输入、范围和细节保留在 [XV-15](xv15-validation.md)、[C–T](caradonna-tung-validation.md)、[配平](trim.md)、[v0.4 工作记录](v040-work.md)、[三方向入口](v043-work.md)。

软件版本不等于模型精度等级。原路线要求的完整动态挥舞、惯性耦合和独立动态验证继续作为操稳模型转正条件；近期软件小版本可以交付经检查的功能，但模型范围和试验性标签必须同步保留。

## 当前工作包：0.4.4 缺陷修复与防误用

状态：**A 包已实现并通过检查，B 包接续实施**。证据见[工作记录](v044-work.md)及[调用数与耗时](../validation/v044/a-performance.json)。先 A 后 B，每包检查通过后提交并同步 GitHub，服务器 SHA 核对后继续。

### A：确定性缺陷和结果可靠性（R02–R06、R16–R17）

- 统一正算、目标反求、批量和整机的速度/Mach 边界：无对应 Mach 数据继续执行模型速度限制；有表时检查实际局部数据域，不被先行 250 m/s 门槛误挡，也不据此自动放开跨声速物理范围。
- 批量图按实际轴向/三方向模型命名；UI 与后端响应时长下限一致。参数不完整时仍显示任务区、错误位置和草稿，运行按钮说明不可运行原因。
- 模态输出检查特征向量条件数、可逆性和特征残差；重根不一律判失败。参与因子不可靠时不排序，保留可用特征根及原因，避免整个分析结果丢失。
- 开环入口显示“开环初评（低频模型·试验性）”；三方向结果显示已有验证范围。结果分别显示求解、支持范围、设计限制和验证依据。
- 确认调用链后移除 `hover_ui.py`、`trim_ui.py`、`open_loop_ui.py`，整理本次涉及的压缩代码；保留原 Julia 高级基准入口。
- 为代表收敛点和边界失败点记录真实残差调用数、nfev/njev、耗时与网格，区分求解、绘图和打包成本；不在本包扩大为全求解器重构。

验收：有/无 Mach 表、三方向标题、合法/非法时长、模态正常/病态、缺项补齐重跑、旧入口导入及旧工况回归；两模板 UI/CLI 同输入一致。记录错误恢复和实际耗时，不以 nfev 代替全部计算成本。

### B：扰动输入与下载边界（R06、R10）

- 响应支持 `step`、平滑 `pulse`、正负 `doublet`；保存类型、幅值、开始时刻、持续时间和观察窗口，旧工况缺省维持原 step 语义。
- 新演示候选为 2 s 窗口、0.2 s 开始、0.5 s 的 sin² 脉冲、0.05°峰值；双脉冲每段 0.5 s，正段之后负段再归零。线性与非线性模型共享输入函数，RK 子步按实际时刻取值，方波断点拆步；导出输入时程及图。
- 下载策略显式选择。悬停预算保留经验比例；新六分量方案默认 `none`（无附加残余比例力），指出机身下洗/下载未完整建模；历史输入按 `legacy_fraction` 读取并可复算，输出实际比例和分项。已有机身/尾翼载荷继续按各自模型计算。
- 同一下载策略贯通配平、线化和时程。禁止用“速度恰为0”切换非零下载，禁止在新版打开旧方案时静默清零。预算与配平不同策略的比较明确列出差异。
- 为新建方案创建有版本的新模板来源，不覆盖历史 `examples/` 基准；0.4.5 在此机制上继续更新方位约定。

验收：两模板的悬停及20 m/s、四操纵、三波形检查实际输入与状态；步长减半和幅值减半检查；明确失稳或越界时的部分输出。新默认经过上述检查后启用，不能把2 s无异常当作稳定性证明。下载项有限差分与解析分项一致，新策略零速附近无硬切换，旧策略可按原模型复算。

## 0.4.5 工程输入与直观理解（R07–R09）

- 新模板主旋翼方位参考直接为机尾 `[-1,0,0]`；保留旧基准、旧包和旧缺省路径。一套实际基底贯通操纵、挥舞、入流、A/B 和图表，不设显示专用翻转层。
- 方位图显示实际机头/机尾/左右关系；前行侧根据旋向和来流计算，悬停只画空间方位，尾桨按自身轴定义。周期变距展示谐波公式和桨距分布，不未经杆系映射就改称驾驶杆输入。
- 默认运动速度视角：水平前向/水平右向/上升为正，姿态默认水平，可在专业区调整滚转/俯仰；与机体系空气相对轮毂 XYZ 视角互换时转换数值。即时中文回显参考系、方向、速度及所选旋翼 μ，实际计算仍只接受一次转换后的同一物理向量。
- 主轴和尾桨安装角生成正交基底，旋向用明确观察方向的中文选项；功率以 kW 输入显示，内部 SI 不变。统一本次工况与参考工况、固定预锥与挥舞配置的来源提示。
- 高度和 ISA 温差联动密度、声速、黏度；自定义环境明确全部实际参数。现有动力曲线若只含高度，不自动杜撰温度降额规律。
- 结果表和诊断采用中文工程名及单位；整机侧视/俯视、弦长/扭转、翼型极曲线随草稿实时预览，来源及原始数据域可见。

验收：正反运动、侧向来流、非水平姿态、主尾桨、双旋向、旧包切换视角与复算；同物理配置基底变换后的机体系载荷一致；海平面/3000/4500 m、非零温差检查；新用户只用页面完成一轮分析。

## 0.4.6 方案比较、模板与工程交付（R11–R13、R18）

- 用根弦/梢弦/线性扭转生成几何；半径扫描提供保持实际弦长、保持实度两种规则，记录质量矩/惯量未更新项。其他实体相似律在来源明确后再增加。
- 扫描提供起点/终点/步长；显示实度、盘载、桨尖 Mach、主尾桨 T/Q/P、功率和操纵余量。主桨 FM 与含尾桨/传动/附件的整机功率指标分开定义，避免混用。
- HOGE 在给定可用功率、操纵和数据域内搜索，给出控制约束；达到输入曲线边界而未找到极限时显示边界状态。HIGE 待地效方法建立后接入。
- Excel/CSV/TXT 使用中文列名、单位、填写说明与来源；导入预览、行号报错，保留高攻角分段语义。方案支持可恢复删除、历史恢复及清晰确认，保留写入冲突保护。
- 首套为200 kg级公开尺寸约束无人直升机参考方案，候选依据 S-100 厂商公开尺寸，逐项列来源和估算；不以真实型号名掩盖缺失的几何/翼型/惯量。完成用途检查与一套可运行悬停预算，补齐可信输入后再启用配平/开环。现有合成机和 UH-60 基准继续保留。
- 基础翼型库随模板交付已有明确来源数据；0.4.7 补低 Re 对称/非对称数据。仅有坐标、不含极曲线的条目不能作为可用气动表。
- 至少三组同条件候选报告包含实际输入、几何规则、载荷/功率分解、限制及来源。现代 Windows 离线分发补标准包元数据与维护说明，不虚报未测 Python 版本。

验收：模板来源覆盖与缺项清单、目标拉力回代、三方案实际计算、失败方案可解释；表格往返、历史恢复、断网和目录搬移复算；同事从双击启动到导出无需终端或 JSON。

## 0.4.7 有界物理改进与验证（R02、R10、R13–R16）

- 先建立相同几何、气动表、预锥、面积、入流/损失条件下的跨入口检查，共用叶素和反求；不同物理假设保留不同结果及解释。消去 fixed 挥舞未知量后复核状态还原、残差、导数和计算成本；反求优化保留多根/无根判断。
- 优先复用 C–T/XV-15，补局部 Re/Mach 覆盖并做同总距/同拉力及径向载荷对照。低 Re 对称 NACA 64A010、非对称 NACA 2414 为首批 UIUC 数据候选；保留现有 NACA0012 原始试验域，不把它宣称为通用低 Re 表。
- 尖损失、诱导功率修正、高攻角延拓分别给方法来源与作用位置；实际数据和工程估计分列，检查误差及敏感性。小面积/动压占比不单独作为越界放行条件，缺少 Re/Mach 数据仍须明示。
- 复现有来源的机身局部下洗/尾迹偏斜载荷，明确经验残余项是否已包含；同条件对照载荷、功率与导数后再替换临时策略。原 GenHel 表适用其配置，不直接套作所有无人机的通用模型。
- 前飞优先检查既有 XV-15 和 UH-60A Airloads 的几何、气动表、操纵、桨毂姿态、工况及测量量；资料完整后完成至少一组定量载荷对照。TM-81232 继续只用于悬停；资料不足时保留缺项，不把数值检查写成前飞验证完成。
- 根据实测瓶颈分离内存求解与导出，复用有效模型对象；架构变化和物理变化分开提交。原始快照、部分失败和旧方案读取保留。

结束条件：提交数值检查、独立误差对照、可用数据域和未关闭项。物理误差未达目标时保持试验性状态，不能宣称该项精度验收通过，也不无限扩大本轮尾迹或数据研究。

## 后续主线与验收规则

需求驱动初步定尺寸在给定方案流程可用之后开展：明确任务、质量角色、设计变量和动力/能量约束，接回同一机型与分析入口。完整动态挥舞、角动量/加速度耦合及横航向独立验证另立操稳升级包。涡环态、自转、复杂干扰、倾转、闭环与 Win7/Python 3.8 保留后续范围。

- 沿用六分量归一化残差 ≤1e-4、旋翼内部稳态 ≤1e-6、关键总量末两级网格变化 ≤0.2%、主要导数差分变化 ≤2%、关键响应时步变化 ≤1%；近零量采用有记录的尺度和绝对门槛。
- 固定总距拉力、同拉力功率、径向载荷误差 ≤10% 是按独立基准分别判定的研发目标，不是当前统一精度承诺。校准、同源留出和独立数据分开。
- 单点预算 ≤2 s、配平 ≤30 s、100点扫描 ≤10 min 为原效率目标；记录硬件、网格及失败点后判断，不用文档篇幅或 nfev 猜测成本。
- 借鉴 AAA_Design：同方案更换模型与重新设计分开比较；输入/假设/求解量/约束分清；载荷与功率账目唯一；假设变化使旧结果成为历史；保存失败及真实用户操作证据。
- 每包检查后提交并推送、核对远端 SHA；开发用 `.devN`，发布须完成该版软件验收及范围说明。正式小版本不自动将试验性模型转正。
