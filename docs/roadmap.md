拟定的孤立旋翼页面顺序：

```text
旋翼方案名称        [新建] [打开] [保存] [更多]
  更多：复制方案、导出方案文件、历史版本与回收站
旋翼设置            总体参数；桨叶运动方式
  详细设置：桨叶几何形状 / 翼型气动数据 / 相关质量与挥舞参数 / 可选限制

求解任务            正算 / 指定拉力反求 / 批量性能扫描
  只显示该任务需要给定的量；求解量进入结果，不混作普通输入
求解器参数设置      生效的入流/损失/插值说明与计算网格
[开始计算]
计算结果            实际输入、载荷、状态与导出结果
```

“保存”写入本机方案库；“导出方案文件”用于分享/换电脑，放在“更多”内。新建才选模板，打开才选本机方案或文件，历史/恢复在有对应记录时出现；未保存草稿在替换动作发生时提供保存、放弃、取消，移除长期摆在页面上的许可复选框。结果页导出的图表与复算包对应实际运行输入，与可编辑方案分别命名。

### C4-B：统一工程含义与参数生效规则（dev17软件检查完成）

- 普通新方案使用同一三方向方位角模型覆盖悬停、轴向及允许范围内的斜流；不按横向速度恰好为零切换另一套入流/损失假设。旧轴流/环带算例按原方法读取，方法对照留在专业区域。只展示当前方法实际使用的参数；不提供能勾选却不生效的Prandtl或环带选项。
- 桨叶运动方式收敛为“铰接挥舞”和“刚性桨叶”。固定模式不显示挥舞惯量、刚度、阻尼等必填项；资料仍属于模块，需要准备装配时可以编辑。切换只启用对应字段，保留原有资料，缺项一次列清。
- 新界面只设一个有效预锥入口，固定模式为给定几何角；铰接模式按当前近似用作弹簧零力矩参考角。实际受载锥度`β₀`为求解输出，不再新增第二个让用户填的“锥度角”。两份历史预锥字段按原有效模式解析，不覆盖原包；必须经过另存和同物理工况核对才能迁移。
- 运动输入采用明确的前右下参考，试验来流采用明确的桨盘轴向说明和坐标示意。零姿态后右上显示与运动速度可按用户所述符号对应；倾斜旋翼、竖直试验台和旧零方位通过实际基底转换。内部桨毂局部系保持，不把固定后右上宣称为所有姿态下的风轴系，不增加整机位置等无关必填项。
- 重力用“重力加速度g”与试验姿态输入，程序投影到桨盘；普通用户不填三个重力分量。固定桨叶计算隐藏无关重力项；历史局部向量及零重力对照保留高级读取语义。说明速度为相对空气速度，不把地速默认当空速；下降等现有不支持工况仍明确拒绝。
- 当前已含Pitt–Peters三状态入流：孤立稳态求平衡，整机时程推进动态状态。在求解器说明中准确显示，C4不新增孤立旋翼时域任务，也不把已有低频模型改称完整高频动力学。

涉及局部坐标入口、有效配置适配、`parameter_fields.py`及相关显示；尽量复用现有载荷、求根和PP实现。完成标志：六个有符号速度方向、双旋向/非零周期、水平与倾斜/竖直试验姿态都能解释；切换输入视图不改变实际工况、总载荷和力矩。相同物理输入比较沿用模块门槛：非近零量相对1e-6，近零力/矩绝对1e-7 SI，挥舞1e-8°；旧模型语义不得为改善界面静默更新。预锥检查覆盖固定角、非零弹簧和自由铰三个分支；`β₀`与输入预锥分别显示。轴向/斜流连续性用同一模型检查，不强求环带与PP结果一致。

### 已写入项目规则的四项约束

1. 新字段进入普通界面前先判断：当前任务是否需要用户给定，能否自动推导；待求量、元数据与不生效参数不冒充输入。
2. 普通操作按用户对象和动作组织，不按内部schema、历史兼容或测试分支组织；同一个动作采用相同名称和唯一数据归属。
3. 模式相关字段按有效配置显示；隐藏不等于删除历史值，也不允许后端继续偷偷使用一个已表示为关闭的选项。
4. 自动检查通过仅代表所查流程可运行。真实用户提出的理解障碍必须回到字段和动作上修复，不以补长说明替代；未完成相关复测不得关闭易用性项。
