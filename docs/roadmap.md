# 无人直升机总体设计分析路线

阶段目标：给定一份方案，快速计算孤立旋翼性能、整机需用功率与配平、动力和操纵裕度、开环动态特性，并比较设计参数变化。

当前基线为 v0.1.0 与开发分支的 XV-15 / Caradonna–Tung 验证包。Python 为产品主线，Julia UH-60 作为数值基准；保留旧工况复算。试验精度与数值收敛分别记录。

## v0.3.0 配平

方位角叶素、周期变距、锥度/一阶挥舞、三状态入流及六自由度机体共用载荷入口；接入机身/平尾/垂尾。先覆盖悬停、稳定正爬升、无侧滑直线前飞（μ≤0.25 且不超局部翼型域）。六分量残差归一化后≤1e-4；检查内部稳态、零速连续性、操纵和功率限制。UH-60 与 Julia 及 NASA TM-85890 按配置和定义互校。

## v0.4.0 开环操稳

同一机型与动力学方程产生 A/B、特征根、参与状态、频响和小扰动响应，显式处理质量矩阵。导数步长减半变化目标≤2%，时步减半响应变化≤1%。输出双向操纵余量及性能—配平—操稳联合比较，不自动判飞行品质等级。

## 验证与效率

保留 XV-15、C–T、UH-60。软件回归、数学模型互校、试验对照分别归档。末两级网格总量变化≤0.2%；固定总距拉力、同拉力功率和径向载荷误差目标分别≤10%，按独立基准判定，未达标保留模型估算状态。原有 C–T 固定总距拉力偏高约29.09%，继续排查但不阻止整机接口开发。

测量本机硬件和网格：预算单点目标≤2秒，后续配平≤30秒、100点扫描≤10分钟。暂缓前飞以外复杂构型、涡环态、自转、闭环与 Win7 分支。复用既有 Hover_BENCHMARK，不重复历史高成本计算。公开仓库只保存公开/合成输入与可公开成果。
