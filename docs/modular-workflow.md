# 独立旋翼模块、整机装配与分析流程

2026-11-17按用户最新操作逻辑修订；2026-11-18已完成M1独立模块与求解入口（0.4.6.dev3）及M2独立网页工作区/模块库（0.4.6.dev4）。见[M1证据](rotor-modules.md)、[M2用法](module-workspace.md)和[检查记录](m2-work.md)。M3整机装配仍待实施；本工作包优先于0.4.6-A2。

## 为什么需要调整

现有`aircraft.prepare`先读取机型，`isolated.run_spatial`从机型取得旋翼并输出关于整机重心的力矩；机型schema也要求质量和重心。页面即使收起整机字段，旋翼仍依附整机文件。应建立独立的旋翼对象，让整机装配引用旋翼，而非孤立旋翼依赖整机。

用户不需要为了分析一个旋翼填写飞机重量、重心、另一旋翼、动力或传动参数。主旋翼和尾桨采用同一种模块类型，其角色在装配时指定。旋翼包含桨叶与桨毂，挥舞是旋翼的物理属性。

## 三层数据归属

|对象|所属参数|独立性与保存规则|
|---|---|---|
|旋翼模块|桨叶数、半径、几何、翼型表、总距参考站、旋向、局部零方位、桨叶质量及铰外质量矩、预锥、铰偏置、挥舞刚度/阻尼/耦合、局部操纵和转速限制；桨毂质量性质及来源|可以单独创建、计算、保存、重开和导出；不含安装位置、机体重心、主尾桨角色或整机动力。桨叶质量与桨毂质量分列，单片与整副旋翼分列。|
|安装实例|所用旋翼模块版本/哈希、主旋翼或尾桨角色、桨毂位置、模块到机体系的安装基底、传动连接、转速关系和效率、操纵映射|同一模块可重复安装；位置和方向属于实例，不回写模块。未实现的布局不能仅凭可装配就宣称可求解。首期整机仍限定一主旋翼加一尾桨。|
|整机方案|安装实例、非旋转机体及其他部件、质量/惯量归属、重心、机身/尾翼气动、动力与传动网络、整机限制|保存完整模块快照与来源，不依赖用户电脑上的外部绝对路径。模块库更新不静默替换已有装配；主动替换后旧结果保留为历史。|

总距、周期变距、实际转速、环境、来流和计算网格属于分析工况，可与模块一起保存算例，但不是一个旋翼的永久物理定义。整机配平中的操纵量是待求量，不自动沿用孤立旋翼的给定总距。

挥舞模型选项和算法假设与实体参数分别记录。例如轴流环带模型与方位角叶素模型的能力不同，保存桨叶惯量不等于轴流求解器开始使用它。参数说明应标出当前分析是否使用该量，新增质量字段不能悄悄修改旧动力学。

## 五个左侧入口

1. **孤立旋翼**：选择或新建模块，设置桨叶、桨毂和挥舞属性；填写工况，正算/反求/扫描，保存模块及算例。页面没有整机重量、整机重心、安装位置、发动机或其他旋翼的设置，也没有展开整机参数的开关。来源于主旋翼或尾桨的预设可以保留说明，但均作为独立旋翼模块使用。
2. **整机装配**：新建或读取整机，加载已保存的模块到主桨/尾桨安装位，指定位置、方向、传动连接和操纵定义，再配置机身、尾翼、动力、质量及限制。常见效率可以用明确标识的工程估计初值，来源、默认依据和未确认状态随方案保存。
3. **悬停求解**：读取装配方案，设置环境及任务条件。区分“悬停六分量配平”和“悬停功率预算”；前者复用零前飞速度的整机配平方程，后者继续按预算模型输出分项需求，不能把预算成功标成整机已配平。
4. **全机配平**：读取装配方案，进行指定速度/爬升条件的配平及扫描，显示实际使用的装配快照、操纵/姿态、残差、功率和限制。
5. **开环评估**：读取装配及配平工况，提供现有低频诊断能力。R19未关闭前保留具体限制，页面重组不改变模型成熟度。

导航切换保留各工作区草稿和已提交结果。模块库、整机库和算例分开管理；普通操作只使用中文表单和可读表格，不要求编辑JSON。原Julia基准保留高级验证入口。

## 孤立旋翼的坐标与载荷

新模块使用桨毂局部右手系：z沿正推力轴，x是模块定义的零方位，y由右手系确定；旋向规定桨叶经过方位的顺序。零方位不绑定尚不存在的机头或机尾。安装时再建立模块与机体的映射。

工况接受局部三分量来流并明确正方向，界面可同时给盘面内速度和轴向分量的直观解释。结果主要输出局部六分量气动载荷，力矩参考点为桨毂，不输出虚构的“全机重心力矩”。整机装配后才做安装变换和移轴。

不需要整机重心，并不意味着忽略桨叶重力：需要重力参与挥舞时，工况给出重力在旋翼局部系的方向，或者用试验台旋翼姿态转换得到。它是本次试验姿态，不是桨毂在飞机上的安装坐标。水平主桨、竖直尾桨式试验和无重力数值对照须可区分。

## 文件、兼容与质量分账

- 新增独立、带版本的旋翼模块包和模块工况；使用相对路径和内容哈希，包含几何、翼型及来源。整机方案引用时嵌入固定快照，运行时保存实际模块与安装版本。
- 新模块校验直接检查旋翼所需参数；不通过虚填飞机质量、单位惯量、零重心或虚构尾桨满足旧机型schema。已有叶素、入流、挥舞和求根实现继续共用。
- 旧`.rdl`和旧CLI保持原模型、坐标及缺省读取路径。另提供“从旧整机提取旋翼模块”，新建输出并保留源包哈希和原安装映射，不原地改写旧包。
- 提取模块的局部零方位与操纵系数一起保存。用旧安装基底把原来流和重力转换到模块局部系，在相同物理工况下比较叶素、T/Q/P及六分量载荷；不能仅删除安装字段后直接比较原机体系输入。
- 现阶段的质量、重心与惯量仍按原整机模型语义复算，不自动把模块质量累加到已有整机质量。A2专门处理新模型的部件分账、质量属性参考构型和加速度耦合；缺项集中列出。未知量可给有依据的工程估计，不填零冒充已知。

## 实施顺序与完成标准

### M1 独立模块与求解边界（已完成）

建立模块/工况格式、用途检查、独立CLI入口及旧旋翼提取器。将旋翼求解与安装后处理分开，共用现有求解核。交付一个合成模块及一个从公开基准提取的模块，桨叶质量、质量矩及桨毂资料的缺项逐项标识。

验收：没有任何整机字段仍可完成固定桨叶和铰接挥舞计算；保存重开和搬移目录复算；改变刚度/阻尼后确认相应方程实际使用新值；非法质量矩、缺失必要挥舞参数有明确诊断。旧模块提取前后在相同物理工况下，T/Q/P及非近零载荷采用相对1e−6，近零项采用预先记录的SI绝对尺度核对。旧CLI回归保持。

### M2 独立旋翼工作区与模块库（已完成）

实现左侧导航、独立旋翼创建/编辑/计算/保存与模块库，整机草稿和模块草稿分别保存。高频工况直接显示；桨叶、桨毂、挥舞与气动表按旋翼对象组织。移除孤立旋翼页的整机详细设置。支持从旧方案提取模块的清晰迁移入口。

验收：从空模块或旋翼模板开始，无需创建整机即可完成计算、保存重开和导出；固定/铰接、三方向来流、正算/反求/扫描均保留；切换工作区、导入失败与重名保存不会丢失草稿或串用结果。新人不需要理解内部文件格式。

### M3 整机装配与三个分析入口

实现模块加载、主尾桨角色绑定、位置/方向/传动设置、装配检查及快照。接回悬停、配平和开环三个入口。普通分析页读取装配完成的方案，不重复编辑第二套旋翼物理参数；修改部件从装配工作区进入，变更后旧结果显式保留。

验收：已算过的模块能加载为主桨或尾桨；同一模块两个安装实例的位姿独立；模块库更新不自动改变已保存整机；实际安装方向、来流变换、重力投影、力矩移轴、操纵符号及配平回归通过。端到端完成“模块计算→保存→整机装配→悬停→配平→导出复算”，开环继续执行R19诊断门槛。

M1、M2、M3各自检查、提交并同步。三个工作包完成后再继续A2；A2通过后进入A3。代码版本按实际交付递增，本次路线修订不递增软件版本，也不宣称模块化已经完成。
