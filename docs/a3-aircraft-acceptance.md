# A3首轮整机验收：通过项、失败项与下一步

2026-11-18，A2基线`b0fb173`，诊断提示更新为`0.4.6.dev7`。**A2实现已提交并同步；A3首轮检查完成，整机物理验收未通过，R19保持开放。** 本轮没有调整气动系数、总距偏置或惯量来拟合参考导数。

## 1. 质量与惯量首先遇到的实际问题

将原OH-6A和UH-60惯量直接解释为“包含主尾桨的总惯量”，扣除主尾桨桨叶/旋转桨毂后，剩余机体惯量不满足主惯量三角关系。所有这类输入均被拒绝，原始失败结果在`runs/a3-20261118/probe/`。这说明现有资料不足以支持该分账解释，不能通过放宽物理检查解决。

为继续诊断，另建明确标注的候选：**把原惯量赋给非旋转机体，再加上旋转部件，保持原总质量和总重心。** 非旋转机体重心由质量一阶矩闭合，总惯量重新组装。这个假设尚未由原资料确认；它不是原公开配置的无误差复现，也没有覆盖原方案。

例如OH-6A总惯量对角元从`446/1219/979`变为约`647.43/1452.09/1293.96 kg·m²`，并出现由尾桨安装位置产生的小非对角项。候选参数和来源见[质量假设](../validation/hub-loads/a3-mass-assumptions.json)。主桨质量候选沿用A2来源，尾桨和桨毂仍为显式估算；主桨质量±20%、尾桨/桨毂质量参数×0.5/×2的敏感性另存。UH-60铰外质量与整片质量、尾桨质量矩的配置一致性同样待核实。

比较保留冻结旋翼状态和准定常消去旋翼状态两个口径。新模型消去入流、挥舞幅值和幅值变化率；旧模型只消去其入流状态。平动导数扣除全部`−ω×v`运动学项。横滚/偏航使用已解惯量矩阵后的加速度导数，与带撇形式对应，不再次乘一次惯量修正。新模型还含隐式加速度耦合，其有效导数与原准静态模型的假设差异保留。

## 4. 响应验收保留两个失败项

合成机悬停四操纵通道检查0.2 s；合成机前飞纵横周期通道及两公开候选的悬停/前飞纵向通道检查0.1 s，共10组。共享sin²输入，0.02°与0.01°，每组时间步减半。步长按全状态谱选择，不仅看低频机体模态；实际输入CSV与完整线性/非线性时程保存在对应运行目录。

- 10组时步检查均通过，最大状态峰值归一化变化0.00161%，低于1%门槛。近零分量峰值分母设1e−9（该状态SI单位），规则预先写在脚本中。
- 幅值减半检查事前采用误差比≤0.35，理想光滑二阶误差比为0.25。合成机15 m/s纵向通道为0.4894，OH-6A 40 kt为0.3782，**这两项未通过**。
- 补充0.002°/0.001°后，OH-6A为0.2477，UH-60前飞为0.2501；合成机为0.00794。合成机结果变化并非简单的二阶比例，仍需多档扰动和零输入漂移分析。
- 对原时程抽样核查：两失败点的主桨攻角距离最近插值节点分别仅0.00101°和0.000165°；原幅值下分别有3/6个叶素跨节点，半幅有2/3个，更小半幅均未跨节点。它支持“分段查表影响局部线性范围”的解释，但尚未排除全部其他非光滑项。[检查数据](../validation/hub-loads/a3-lookup-audit.json)。

这是短时软件与局部线性一致性检查，尚未覆盖常用2 s窗口、各波形和所有操纵方向的物理验收。原长批次在完成合成悬停四通道及其网格点后主动停止，保留已完成结果；后续代表点采用独立短响应批次，避免无差别重复计算。两项失败没有被更小幅值结果覆盖。

## 5. 下一步按三个明确任务收口A3

1. **确认惯量归属与配置。** 优先查OH-6A惯量是否含旋翼、参考挥舞和铰内外质量；补尾桨与桨毂来源。没有新证据时保留两种解释和估算边界，不以某组导数更接近为选择依据。
2. **限定局部线性范围。** 在两个失败点做零输入漂移、正负多档幅值、插值节点与气动/机身分段检查，确定可报告的小扰动范围。若采用更光滑插值，必须显式版本化并核对原气动表、配平和导数，不默认替换旧模型。之后扩展到2 s窗口及代表波形。
3. **完成整机物理验收。** 分解剩余前飞导数差异；补UH-60尾桨相应Re范围数据后再复核80 kt；核对保留状态的功率/动能收支及模态对照。瞬态轴功率限制与方法功率口径继续在B包专项处理。

本轮仅收口A2，A3仍在验收中。新旧开环模型均保持诊断用途限制；正式0.4.6不发布。原公开模板、历史包和Julia基准不变。
