## UH‑60 80 kt

- 基准提交为 `05f3872a395c3bec7a983d4eb13c0a3ee42f3261`。四个公开 MAT 文件经 SciPy 按原矩阵形状写入临时 CSV。原始垂向加速度索引复算用时 36 次迭代，独立加权残差为 0.0004968302673660219。横向杆、纵向杆、总距杆和脚蹬分别为 49.7189754%、35.1178111%、33.9015417%、50.8693983%。
- 更正垂向加速度传递后，平飞配平数值与基准一致。固定方位质量矩阵对应垂向加速度的列差二范数为 0.0629254。该范数只记录实现变化。解析一阶隐式系统核对了 `F/G/M/A/B` 和子步加速度求解，NaN 残差正确返回失败。
- 非线性横向脉冲时程采用 0.01、0.005、0.0025 s。相邻步长在共同采样点上，姿态和角速度各分量的最大数值差分别为 2.2974e−5 和 6.0301e−6，单位随分量为 rad 或 rad/s。这组结果用于验收短时数值收敛。

### 图 3 频响复现

从论文第 11 页直接提取三组图的红色全阶模型、紫色飞行试验及相干度矢量路径，用印刷刻度标定横轴和纵轴。采用 0.1–30 rad/s 的 301 个等对数间隔点，并额外输出指定频点。先对参考曲线的相位解包再插值，相位差取最短有符号角，范围为 [−180°, 180°)。依据公开代码的 `perc2in` 和原横滚绘图公式，将本地频响由每操纵百分点转换为每英寸，横滚、俯仰各加 20.00 dB，脚蹬加 25.38 dB。图轴只标 dB，三通道的数值吻合验证了该换算。 [论文 DOI](https://doi.org/10.2514/6.2022-2354)

**论文图 3 数值复现通过。** 原入口以 `A,B = linearize(...)` 接收前两个返回量 `F,G`。按这个口径复算，三通道相对红线的最大点差均低于 0.01 dB 和 0.09°，处于 PDF 坐标读取和插值量级。由此可定位论文红线的计算口径。按隐式动力学正确求解 `A=M⁻¹F、B=M⁻¹G` 后，本地矩阵的 `MA−F`、`MB−G` 最大元素分别约为 2.1e−13、4.4e−16。偏航在 0.1–0.5 rad/s 相对论文红线的 RMS 为 8.85 dB / 77.25°。保留原垂向索引但使用 A/B 时，同样出现该偏差。方位平均也未消除它。应用使用修复后的 A/B。
