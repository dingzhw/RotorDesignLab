# 0.4.3 操作修正与孤立旋翼三方向来流

2026-11-15；起点 be30e86，沿用 codex/rotordesignlab。用户试用发现总距入口难找、参数说明不足，并要求孤立旋翼计算三方向来流。此前0.4.2的自动检查覆盖数值传递，没有充分检查首次使用时的可发现性。

本轮分两个工作包：先把总距与转速放到孤立旋翼计算页，补提示和术语；随后复用现有方位角叶素与稳态Pitt–Peters入流/挥舞模型接入三方向来流，检查坐标、载荷、数据域及导出复算。Excel/TXT整体导入另轮推进。

现有轴流均匀/环带模型保留原数值口径。三方向来流不是把合速度代入轴流公式，使用逐方位角叶素速度与载荷。当前开发版本0.4.3.dev1，本轮不扩大已完成的物理验证结论。

原文件与SHA-256保存在 runs/v043-backup；检查日志和过程文件在 runs 下。本轮保留用户未跟踪的论文PDF。

## 工作包二：三方向来流（已检查）

- 新增`spatial_rotor`适配器，调用现有方位角叶素、稳态三状态入流和一阶挥舞。机体系空气相对轮毂速度取反后转换到原内核的轮毂相对空气速度；主尾桨分别按自身安装轴计算。求解方程保持既有口径。
- 页面直接给X/Y/Z，支持同时非零；支持周期变距、固定或机型挥舞、指定拉力反求总距/转速、来流分量扫描。气动力和关于轮毂/重心的气动力矩分列，新增中文方位角载荷图。
- 新方案默认三方向模型，旧方案包显式迁移为原轴流选项；原轴流CLI、公开基准和计算结果保留原口径。新结果包含实际机型、来流、模型选项、输入快照及便携方案。
- 范围：正推力、正功率、非负正贯流、μ≤0.25及局部翼型数据域。缺失挥舞参数、反向贯流和超范围来流会明确失败。未接入展向气动力、非定常失速或新的尾迹模型。
